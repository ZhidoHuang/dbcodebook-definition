# 定义任务角色与写入边界规则

## 适用范围

本规则适用于所有数据库变量定义、返修和正式重生任务。

## 允许写入

定义任务只允许写入：

1. 当前主题正式目录；
2. 当前主题执行目录；
3. 主题完成后需要原位更新的主题索引和定义验收台账。

除此之外的写入，必须拆成独立任务，并由用户明确批准。

## 定义角色

定义任务负责从现有来源中检索、选择、解释和定义变量，并生成当前主题的正式成果。它不是网站维护、数据库维护或上游数据加工任务。

定义任务可以：

1. 使用 dbCodeBook 已有页面和既有接口进行目录浏览、普通检索、变量选择和数据下载；
2. 只读查看网站源码、生产数据、官方材料、Harmonized 材料和既有定义，用于理解来源与核对事实。

通过网站正常浏览、检索、选择和下载时，由网站自行产生的会话、下载、积分或审计记录属于网站正常运行，不属于定义任务篡改数据。

## 禁止越界

定义任务不得：

1. 修改网站源码、网页逻辑、数据库脚本、生产数据库、生产数据或旧数据库副本；
2. 直接执行 SQL、ORM 写操作、迁移、导入、同步、修库脚本或文件级编辑，改变网站或数据库内容；
3. 因网站缺少变量而修改上游数据、网页、目录、下载逻辑或数据库生成逻辑；
4. 从本地 DTA、Parquet、旧下载包、既有主题数据、Harmonized 数据或其它数据库文件补列、拼接、替换或重建正式 raw；
5. 为绕过路径或写入限制创建、修改或删除 `SUBST` 盘符映射；
6. 修改其它主题，或把网站维护、数据修复和定义工作混在同一个任务中。

正式 raw 只能来自 dbCodeBook 网站本次实际下载的数据包。官方材料、Harmonized 数据和其它本地资料只能用于理解与核对，不能替代网站下载数据。

是否需要重新下载，只看最终来源清单有没有变化，不看主题是新建、拆分还是改名。来源清单中的变量、周期、文件、来源身份或最终别名只要有一项变化，就按改变后的完整清单从网站一次重新下载；不得筛选旧包或拼接补充下载。来源清单没有变化时，不因文案、展示、注释、主题编号或同一批 raw 上的实现调整重复下载。

## 来源缺口

如果 dbCodeBook 的正常目录浏览、普通检索和页面下载不能提供所需来源，定义任务必须停止并报告缺口，不能自行改造网站、修复生产数据或从本地材料补齐后继续。

如果确实需要修改网站或上游数据，应结束当前定义任务，另行建立维护任务，并取得用户明确批准。维护完成后，再从网站重新检索和下载，重新开始定义。

## 网站发布

变量定义与成果生成阶段不能提前写网站。当前请求已经包含“更新网站”“同步网站”或完整“文案审核”时，机器闭环和全文审核通过后直接进入网站检查同步阶段，不再重复询问确认；请求明确限定为只处理本地成果时才停止在本地。第一次网站写入前必须运行公共检查器的 `verify-ready`，确认发布许可和四份正式成果仍是同一版本。

网站发布只能使用网站现有的正常发布页面或已经批准的发布接口。不得为了节省时间直接执行 SQL、Django ORM、数据库文件编辑或临时同步脚本；网页编辑器超时、附件较大或正常发布失败都不构成绕过理由，应停止并报告具体阻塞。

网站同步统一使用外部配置指定的 Google Chrome 通道、可视窗口和专用持久化用户目录。已经存在同一专用目录启动且登录有效的 Chrome 会话时，继续复用该会话；不得改用应用内浏览器、Playwright 默认 Chromium、临时访客配置或另一套 Chrome 用户目录。只有现有会话不存在时，才按外部配置启动新的持久化 Chrome。

必须在清空正文、移除附件或改动表单之前确认登录状态。未登录时停在未改动的编辑页，请用户在该 Chrome 窗口完成登录；登录有效后继续原任务，不重新询问是否同步。

### 固定步骤

1. **确认本次对象。** 明确文章编号、唯一编辑页、正式正文路径、网站目录标签，以及本轮是否需要替换封面或附件。目录标签只能沿用主题索引、验收台账或同一业务组既有文章已经使用的登记标签，不能从文章标题、主题中文名或英文名临时造新标签。上述信息没有同时明确时，不得开始浏览器操作。
2. **锁定一个已登录的 Chrome 编辑页。** 先复用外部配置指定的持久化 Chrome 会话并确认登录有效，再锁定唯一编辑页。一次同步从开始到网站返回结果只使用这一个编辑页。目标编辑页已经存在时继续使用，不再打开同一地址，也不新建窗口、标签或并行编辑会话。
3. **等待页面真正就绪。** 必须看到原正文、封面和附件列表已经载入，不能只看浏览器的“页面加载完成”。页面可能停在旧滚动位置，应先回到顶部并点击标题输入框激活当前编辑页，再重新读取可见控件。每次真实点击后都重新读取页面，不复用点击前的位置。
4. **一次替换正文。** 真实点击可见的“清空内容”，确认编辑栏为空；再真实点击可见的“导入正文”，一次选择完整正式 `.md`。导入可能是追加而不是替换，因此必须先清空；导入不会自动提交，同一次编辑中不得重复导入。
5. **只处理确实变化的文件。** 封面或附件没有变化时保留网站现有文件。定义笔记规定的 `analysis_db`、`analysis_codebook` 固定上传到“侧栏文档”，不得放入“正文文档”；附件变化时，先在尚未提交的表单中从原位置移除旧附件，再从可见的“侧栏文档”上传区域按 `analysis_db`、`analysis_codebook` 的顺序逐个上传。只有正文明确包含 `[DOCUMENTS]` 且任务另有规定时，才可使用“正文文档”。不得为了测试流程重复删除和上传。
6. **提交前只检查一次。** 直接读取正文编辑框，确认文章身份、字符数、开头和结尾与正式笔记一致；不读取整个页面，不复制整份正文，也不重复计算全文哈希。附件未替换时只确认原附件名称仍在，不调整历史顺序；本轮替换时才核对新文件名称和规定顺序。
7. **提交并停止。** 点击“发布”或“更新文章”。网站返回文章详情页即表示同步成功；发布后不再重新打开或检查正文、附件和详情页。

### 备用方式

只有可见的“导入正文”确实无法使用时，才允许人工粘贴。先用编辑器的“清空内容”按钮清空，再一次粘贴全文；不得使用 `Ctrl+A` 或全选删除，不得分段粘贴、循环拼接或在多次浏览器操作之间续写。Windows 剪贴板与内置浏览器剪贴板没有明确验证相通前，不得混用。

### 立即停止的情况

- 页面尚未显示原正文或现有附件时继续等待，不提前点击。确认页面已经就绪后，文件选择窗口仍未出现，才判定失败。
- 取消文件选择、文件为空、格式不支持、读取失败、正文不完整、本轮附件未出现、浏览器连接中断或已锁定编辑页失效时，立即停止。若尚未提交，重新载入同一编辑页，使页面恢复网站当前已保存内容，然后报告具体阻塞。
- 停止后网站同步仍记为未完成。只有用户重新下达同步指令，才从网站当前已保存状态开始新的一次同步。
- 总耗时从收到执行指令开始，到网站返回成功或明确停止为止，浏览器连接、失败和排查都计入。复用已登录会话更新既有笔记以 1–2 分钟完成为目标；本轮需要登录时以 2–3 分钟完成为目标。总耗时超过 3 分钟仍未成功时立即停止，用大白话说明卡在哪一步，不继续盲目重试。

### 禁止动作

- 不直接触发隐藏文件输入框，不用坐标猜测上传入口，不用看似点击但没有真正打开文件选择窗口的合成调用。
- 不调用、查找或临时新建围绕文件选择窗口的通用上传器；已有可见控件可以完成的操作，不再包装新工具。
- 不连续重连、重复打开编辑页、反复点击、分段补写、改走隐藏控件，或在导入外层增加等待富文本完整渲染、循环读取正文等包装。

## 执行方式

本规则约束定义任务实际执行的角色和行为，不要求为网站、数据库或源目录建立哈希基线，也不在每次 R 运行前后扫描它们是否变化。

正式 runner 只检查定义脚本、来源记录和正式成果本身。是否遵守本规则，以任务实际执行的操作为准；不能用机器检查未发现变化来替代角色边界。
