# 问卷任务

入口：已按 [文案入口](../stages/03-copy.md#问卷展示判断) 决定展示或修改问卷。
输入：逐期题干、选项、对象、回顾期、提问路径及原问卷标识与数据变量对应。必要事实不足先核实受影响部分，不用模板补造。

## 执行

1. 先按题间跳转、依赖和连续追问确定展示题组，保留相关上游题；需要时再设内部小标题。
2. 在已定展示范围内比较题义、选项含义、对象、回顾期和路径，确定时期。题组与结果树不必同层。
3. 比较共同选项时，使用整个本组本期的应展示题目，不能先剔除数量或日期题再比较。
4. 对每道题，按下方“进入条件与跳转”表确定跳转属于哪个选项或判断位置。顺序作答不写跳转；已清楚交代的进入条件不重复；尚未说明的必要限制保留。
5. 按基础模板将题干、变量备注、选项及其去向组装成完整题块。能归入选项的跳转随该选项输出，不在题块后再次输出。
6. 按 [Copy-operations](../copy-update.md#copy-operations) 更新适用展示字段，保留原题证据。

产出：题组和时期、完整中文题块与对应登记。每期能独立阅读，标签不含未核实或不适用时期。
验收：来源/语义核对分组、翻译和完整性；现有程序核对它实际支持的题文、选项、路径与定位，不代替来源完整性。
失败：事实、路径或原始名未明回来源；已知内容的层级、译文和格式留本任务；正确标记显示错误回第5步。

## 内容与语法

### 问卷内容与格式

**内容要求**：

1. **题组分组**
   - 每个题组对应一个话题标签，组内设置时期标签。只有一个题组时也显示这两层标签。
   - 根据题目之间的联系划分题组。有跳题、前后依赖，或围绕同一内容连续追问的题目，放在同一题组内；题目较多时用内部小标题分块。没有明显联系的题目，即使属于同一个宽泛概念，也可分别成组。问卷中位置相邻，不代表必须合组。
   - 构成树表达结果关系，问卷题组表达怎样提问，二者不必逐层对应。
   - 内部小标题只用于分块，不另算题组。
   - 题组名称准确概括本组内容，优先沿用已有名称；不按每个计算结果或每道题重复建块。

2. **时期分组**
   - 题义、选项含义、适用人群、回顾期和提问路径相同的时期，合并展示；有实质变化的时期另列。根据已核实证据比较这五项，不只比较展示文字。
   - 注意：仅变量名、题号或编码写法不同，也不拆时期标签。
   - 一个成分发生变化，不要求其他成分一起拆分。
   - 不在整篇前面集中共同题、后面统一补各成分的变化题。

3. **问卷设计／问卷设计变化**
   - 首个时期组介绍调查对象、提问内容和顺序。
   - 后续时期组先说明相较哪个时期，哪些人的哪些问题发生了什么变化，再补充必要设计信息。进入条件改变时，写出实际条件，不只写“受当期分支限制”。
   - 仅选项编码写法变化时，在本组已有的设计说明中集中说明变化时期、编码及含义；其余时期合并说明。不逐题重复，各题只列共同标签。
   - 导出后的解码值另作说明，与原问卷编码分开。
   - 每个时期标签保留必要的完整题干、选项和提问路径，不让读者切换标签寻找。进入条件是否重复展示，按下方“进入条件与跳转”处理。
   - 不同题组之间的区别，不写成跨期设计变化。

4. **原始问题**
   - 展示完整中文题干、选项、单位及必要提问说明，包括影响进入条件的上游题和相关跳转。
   - 共用的引导语或访员说明放在本期设计说明中一次展示；只适用于部分题时，注明适用题目。各题保留自身题干和特有说明，不反复附上整组引导，也不遗漏改变题义或作答方式的限定。证据中的题干与说明分开登记，见[文案程序操作](../copy-update.md#copy-operations)。
   - 已有清楚题组时，不为凑层级重复分块。
   - 共同选项的展示位置和适用范围见下方“选项”；不同的进入条件和跳转分别保留。

**格式要求**：

标题按以下层级组织。一个题组和多个题组使用相同结构。

| 内容 | 标题层级及名称 |
| --- | --- |
| 全节 | 二级“问卷” |
| 题组 | 三级实际题组名称，每组有自己的时期标签 |
| 时期 | 四级适用时期；标签尽量简短，按下方规则表示实际包含的调查期 |
| 设计说明 | 五级；同一题组首次用“问卷设计”，跨期变化另列时用“问卷设计变化” |
| 不设内部小标题的题目 | 五级原问卷标识 |
| 需要内部小标题时 | 五级内容名称，其下题目用六级原问卷标识 |

不机械复制构成树的领域、成分和分项层级。

时期标签：

- 连续调查波次，或按固定间隔连续开展且均已核实的调查年份，使用简短起止范围，例如 `Wave 1–3`、`2004–2022 年`。年份范围表示其中的调查期，不表示每年都有调查。
- 中间缺期或间隔不规则时，列明实际时期，也可组合范围与单期，例如 `2004–2010、2014 年`。不能为缩短标签而包含未核实或不适用的时期。
- 文案不手动插入换行；长标签由网站自动换行。逐期变量对应仍在题目旁保留，不因缩短标签而删减。

题目标题与正文：

- 题目前保留原问卷的标识：原来是题号就用题号，是变量名就用变量名。合并多个时期时，使用第一个时期的标识。
- 题干后用“各个时期的变量名：”列出原始数据变量名，不另列各期问卷题号。备注放在选项之前，使用已有的小字号说明样式；与标题相同且没有补充信息时，不重复写。
- 共同前缀或后缀明确时，可以用范围或分段简写，但不得混淆实际变量名及适用时期。无法明确简写时列出实际名称；范围中有缺项时，拆开列出。不同情况用分号分隔，变量名使用 inline code。
- 时期和简写范围依据已核实来源确定。适用对象和跳题条件按下文分别展示，不混入变量名备注。
- 题干不加引号；设计说明中概括的问题用中文双引号。
- 已符合[题意概括的证据条件](../evidence-and-literature.md#questionnaire-evidence)、无法取得完整原题时，在设计说明中分别写“题意概括：”和“未取得完整原题的原因：”，与证据记录一致。不编造题号或选项；必要事实未核实不能仅靠这段说明继续。

选项：

- 用短横线列出，保留原始编码和标签。
- 先按上方展示范围确定本题组、本时期需要展示的问题，再比较这些问题的选项。
- 所有这些问题的选项编码和含义完全相同时，第一题完整展开，并说明其余题目共用这些选项。不跨时期标签省略必要选项。
- 共用选项的后续题目有跳转时，只列出触发跳转的选项，紧跟去向；其余选项省略。例如：`- 1 没有困难 → 跳至 DB004。`
- 选项不完全相同时，各题分别展开。不为共用选项删去必要问题或重新拆组。
- 连续题号可写：`DB001–DB015 的选项设置相同，后续题目仅列有跳转的选项。`；不连续时列明本题组其余题号及所引用的第一题。

进入条件与跳转：

写清实际跳转的触发条件和去向。正常顺序作答不写跳转提示；只有实际跳过题目、转入其他部分或结束题组时，才标明去向。

| 情况 | 写法及位置 |
| --- | --- |
| 某选项触发实际跳转 | 紧跟触发选项写 `→ 跳至 题号` |
| 跳转无法归入某个选项 | 在实际判断位置写“跳题说明：”，说明触发条件和去向 |
| 整组作答后才判断 | 在该组末题后写触发条件、组合关系和去向，不提前挂到首题 |
| 不再返回本主题 | 写 `→ 结束该主题`；按[结束主题的展示登记](../copy-update.md#结束主题的展示登记)保留原去向及逐期核实依据 |
| 尚未交代的必要进入限制 | 用“适用对象：”说明；没有则省略 |
| 需要补充的进入条件由多题共同决定 | 写全各题回答及“同时满足”“满足任一”等组合关系 |
| 只有题号不足以说明适用对象 | 补充题义 |
| 前文跳题已清楚交代进入条件 | 后续题目下不重复写该条件 |

跳过哪些题会影响结果理解时，再说明这层影响；具体赋值或补值方法放在 Criteria。

同一题组有多条条件分支、逐题文字难以讲清时，在对应时期的相关题目后补简短分支流程图。
图中标明判定题、回答和去向，使用 `text` 代码围栏。
图不能代替完整题干、选项或跳题说明。

## 基础模板

**单一题组模板**（选项、进入条件和跳转只在实际存在时填写）：

按本页“时期分组”要求合并设计相同的时期。仅变量名、题号或编码写法不同，也使用同一时期标签；具体写法见下方题干后备注和“多期相同问卷的展示格式”。

时期标签示例：已核实的 2004、2006、2008、2010、2012、2014、2016、2018、2020、2022 年调查合并展示时，标题写 `#### 2004–2022 年`。连续波次可写 `#### Wave 1–3`；缺期或间隔不规则时列明实际时期。长标签不手动换行，逐期变量对应仍保留在题目旁。

```markdown
## 问卷

### {题组实际名称}

#### {适用时期}

##### 问卷设计

{首个时期说明问谁、问什么、怎样提问、用于哪些结果。整组共用引导语在这里展示一次，单题特有说明留在对应题目。后续因设计变化另列时，标题用“问卷设计变化”；先写相较哪个时期、改变了什么，再补充必要设计信息。各时期均保留必要的完整问题块。}

##### {原问卷变量名题号}

{完整中文题干}

各个时期的变量名：{适用时期} `{原始数据变量名}`；{适用时期} `{原始数据变量名}`。

适用对象：{前文尚未交代的必要进入限制；无则删除本行}

- {原始编码} {选项标签}
- {原始编码} {选项标签} → 跳至 {目标题号}

跳题说明：{不能归入选项的真实流程；无则删除本行}
```


## 条件实例

- 实际有独立题组或跨期变化：读实例“多个独立题组模板”，再定位与本组变化有关的例子。
- 同组需要内部小标题：读实例“题组内部需要小标题时”。
- 多期设计相同：读实例“多期相同问卷的展示格式”。
- 前置题与正式题有跳转联系：可读“分期问卷的展示格式”中的 ADL 写法，不复制其算法。
- 已满足题意概括证据条件且拿不到完整原题：读“仅有已核实题意时的展示格式”。
- 原始名与下载别名区分：必要时读题干后备注的位置示例；取已核实的原始数据身份，不仅凭字段名 raw_variable 推断。

实例保存在 [reader-copy](../../../templates/reader-copy.md#4-问卷调查实际问了什么)。用标题或示例名称定位所需片段，不以模板中列了某题为采用它的理由。
