# 普通写作任务

每个最终变量都按本页要求编写 Criteria。完整写作依次完成适用的Criteria、标题摘要、小book和资料，再组装。已完成且未变的内容沿用；局部任务直接定位本次操作，不顺序重写其他栏目。
共用表达、inline code、依据/问卷/树的触发条件均以 [文案入口](../stages/03-copy.md) 为准。

## Criteria任务

- 入口：相应变量的已定事实足以说明取值。
- 输入：最终变量清单、来源、时期、算法和特殊缺失条件；结果关系已在方案确认。
- 操作：先按依赖关系核对成分与综合结果的方法，再编写。以 `analysis_var` 作三级标题，成稿按最终变量清单排列。将该项的含义写入“定义”，构建方法写入“定义逻辑”，最终取值和单位写入“分类”；需要单独说明的含义或跨期口径差异写入“注意点”。各栏目按下方写法表达，树和字典也取自这份方案。
- 产出：与最终清单一致的 Criteria，不新增输出变量。
- 验收：对照已定方案和 R 核实正文中的公式、评分及分类标准；按[信息取舍](../stages/03-copy.md#解释性文案的信息取舍)核对内容是否放对位置。读者应能理解结果怎样得到，不需要跟着代码处理每条记录。机械格式检查不能代替这项核对。
- 失败：事实或方法未定回来源；已定事实表达有误留本任务；实现错误归公开 R。

## 5. Criteria：每个变量怎样得到

**目的**：让读者理解变量表示什么、主要怎样得到，以及怎样正确使用。

- **内容要求**：每个最终变量填写一组，名称及顺序与方案的最终变量清单一致。
- 当前变量的主要计算、评分或分类标准写在“定义逻辑”中；缺失说明按下方第3项的范围填写。不在 Criteria 开头另放共同处理段落，也不用“符合共同条件”等引用代替判定条件。

| 栏目 | 内容 |
| --- | --- |
| 定义 | 用一句话说明变量表示什么，带上必要的对象、回顾期或单位 |
| 定义逻辑 | 说明当前结果怎样组成、计算或判定；成分按下方要求展开或引用 |
| 分类 | 按[最终变量取值](../stages/01-source-plan.md#最终变量取值)核对方案，列出有效、非缺失取值及含义。NA 不列为分类。数值变量说明类型和单位。不拿原问卷编号替代结果取值；实际分布留在QA |
| 注意点 | 写本变量需要单独说明的含义或跨期口径差异，按[信息取舍](../stages/03-copy.md#解释性文案的信息取舍)确定范围；没有就省略 |

定义逻辑讲清当前结果的核心构建：使用什么关键输入，怎样计算、评分或判定得到结果。解释到读者能理解主要方法，不按固定层数限制；已有说明不重复，无关细节不展开。按实际内容选择文字、公式或表格；数据处理说明按[信息取舍](../stages/03-copy.md#解释性文案的信息取舍)留在 R。

数值阈值优先用 `>`、`≥`、`<`、`≤`，准确区分是否包含边界，如“年龄 ≥60 岁”“≥3 项阳性”。条件之间用“且”“或”等文字说明。

1. **讲清核心构建。** 说明关键输入代表什么，以及怎样得到当前结果。成分说明可以放在计算或判定标准之前，也可以放在之后。
   - 直接使用原始测量或回答时，写清其含义、官方变量名及取用、合并或判定方法；可标明对应周期。
   - 成分已有独立定义说明时，引用成分名称及正式定义变量名，说明它们怎样参与当前结果的构建；保留理解核心方法所需的解释，不重复完整构建过程。
   - 成分没有独立定义说明时，在当前变量的定义逻辑中说明成分的主要公式、评分或分类标准，以及合成方法；不展开原始记录的整理过程。不能仅因 R 已计算该成分，就省略其定义标准。
   - 变量名放在对应含义旁的括号中，使用 inline code。原始输入使用官方名称；下载别名只用于 R 和来源映射。

   按实际处理选择写法：

   | 实际处理 | 写什么 |
   | --- | --- |
   | 原有含义、分类或数值不变 | 写明直接取用的上游变量及其含义 |
   | 重新分类 | 写清哪些回答归入哪类 |
   | 换算或合成 | 写清计算方法、单位及必要权重 |
   | 只统一代码或标签 | 写明取用的上游变量及其含义；具体取值放“分类”，不重复整套对应 |

   沿用实际计算中的成分，不凭同名认定方法相同。说明组分不改变最终变量清单，也不因此增加独立的 Criteria。

2. **范围说明放在对应方法旁。**
   - 定义方法随对象或时期不同时，写清对应条件；成分的独立定义已说明时直接引用。
   - 方案中的共同内容，只有影响本项定义标准的部分写入正文；数据准备按[信息取舍](../stages/03-copy.md#解释性文案的信息取舍)留在 R。
   - 原始输入随周期变化时，可按“周期—变量”紧凑说明。含义、检测方法或对象发生变化时，写清影响当前构建的区别及衔接方式；不把这些信息当成无关的字段映射省略。
   - 时期和名称依据已核实来源确定，简写不得混淆来源及适用范围。
   - 同一变量保留跨期口径差异时，定义概括共同概念并点明差异，定义逻辑分别说明各期取值，注意点说明比较限制。是否合并按[跨期结果合并](../stages/01-source-plan.md#跨期结果合并)，不在写作时自行拆分。
   - 不用“按当期题义对应”“依口径处理”代替具体说明。

3. **缺失说明只写以下三类，放在对应方法旁。**

   | 情况 | 写什么 |
   | --- | --- |
   | 完整性要求 | 写清需要哪些回答有效才能计算，例如“六项均有效时才计算” |
   | 缺项计算、补值或折算 | 写清适用条件、允许的缺项范围、处理方法及计算边界 |
   | 前置筛选题的回答直接决定结果，需补0或设为缺失 | 写清触发回答、组合关系、适用时期和必要例外 |

   原始缺失、拒答、不知道和特殊编码的缺失转换，不专门写进定义逻辑。不写笼统的“其余记为 NA”。

   异常值剔除和数据一致性校验留在方案和 R 中，不作为正文披露要求。

所有条件都来自已确定方案，原始回答用真实选项。调查提问流程放问卷；本变量的含义或口径提醒放注意点；数据处理说明按[信息取舍](../stages/03-copy.md#解释性文案的信息取舍)放入 R。不为完整形式增加背景或步骤。

**格式要求**：

- 二级标题用“Criteria”；三级标题用实际变量名；四级标题依次为“定义”“定义逻辑”“分类”“注意点”。
- 变量名及代码格式见[通用格式](../stages/03-copy.md#通用格式)。
- 多步定义用①②③分项。
- 分类用短横线，取值、编码及类别用方括号。
- 并列阈值、评分标准或不同情形用表格更清楚时，在栏目内用 Markdown 表格，表前后用短句说明必要条件及合成关系。简单定义用短句或公式，不强行做表。生成器负责呈现真实表格，不将表格行作为普通段落输出。
- 没有注意点时删除整个栏目。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#5-criteria每个变量怎样得到)。


**模板**（一个变量一组；此处不预设赋值、补零或缺失处理）：

栏目格式按 [Criteria 要求](#5-criteria每个变量怎样得到)，变量名格式统一见[通用格式](../stages/03-copy.md#通用格式)。

```markdown
## Criteria

### {analysis_var}

#### 定义

{该项 display_name 所表示的含义；带上必要的对象、回顾期或单位。}

#### 定义逻辑

{当前结果的核心构建：关键输入的含义、名称及主要公式、评分或判定。原始输入可标明周期；已有成分引用其定义，理解核心方法所需的成分标准仍要讲清，不重复完整上游过程。}
{当前结果的判定或完整性条件；缺失说明只按上方三类填写。没有则删除本行。多步定义用①②③分项。}

#### 分类

{分类变量逐项列有效、非缺失取值及含义。NA 不列为分类。数值变量填写类型和单位。}

#### 注意点

{本变量必要的使用说明；没有则删除本栏目。}
```


实际为跨期合并结果时，定位实例“跨期来源的紧凑写法”“同一变量保留跨期口径差异”；合成时，成分已有独立定义说明的读“计算公式与计算条件”，没有的读“组成项未单独定义”；涉及前置补值时读“前置跳题补零”。不把实例的事实套到本主题。

## 标题与摘要任务

- 入口：相关定义含义明确；只改措辞时沿用原已定事实。
- 输入：最终结果名称、数量及已定关系。
- 操作：按下方标题和摘要规则表达；树确实需要新写或修改时进入 [树任务](tree.md)。
- 产出：标题和一个摘要自然段，以及适用的树。
- 验收：各结果可识别、数量正确、不把分组或中间量当输出；文字不能改变方向与时期。
- 失败：清单或关系未定回来源；表述、标记问题留文案。

## 2. 标题

**目的**：让读者识别数据库和主题。

**内容要求**：主题名称准确覆盖实际定义，不扩大范围，也不堆列所有变量。中文与英文含义一致。

**格式要求**：一级标题，使用“数据库 — 中文主题（英文主题）”，不加主题序号。

**模板与实例**：[查看本部分](#2-标题)。

## 3. 摘要：最终得到什么

**目的**：让读者知道本主题定义哪些内容，共多少个变量。

**内容要求**：

- 尽量简短地介绍全部最终变量及总数。每个结果都要点到，允许用简短名称和适当归纳，不必重复完整名称。
- 同类变量按结果维度分组。共同名称放在括号外，括号内用短语列出各变量的对象、时期或指标区别；不能只写宽泛类别或数量代替具体结果。
- 分组按主题实际内容确定；内容较少时可直接列名。直接列名且有综合结果时，先介绍综合结果及其分类，再介绍分项；分组介绍时按内容关系安排顺序。

- 结果关系交给下面的关系树；具体定义、判定条件、单位、得分方向及赋值和计算方法写在对应变量的 Criteria；跨结果提醒按[小book任务](#小book任务)的范围填写。
- 摘要只保留识别不同结果所需的对象、时期或指标词，不展开上述解释。
- 是否展示关系树按[入口的使用条件](../stages/03-copy.md#关系树)判断；Criteria 须独立讲清变量的含义和取值方法。

**格式要求**：

- 二级标题用“摘要导读”。
- 摘要文字写成一个自然段，不拆成表格或逐行列表。
- 需要关系树时，将树放在该段之后。
- 每个最终变量连续编号，分组本身不编号。文案用①②③；超过50时写 `[[序号:51]]`、`[[序号:52]]`。生成器统一绘制等大的圆圈，并按数字位数缩小圈内字号。
- 分组写法：`本主题定义 **数量** 个变量：**共同维度**（①具体结果、②具体结果）；**另一维度**（③具体结果）。` 括号内可用斜杠归纳共同表述。
- 直接列名写法：`本主题定义 **数量** 个变量：①“**结果一**”、②“**结果二**”、③“**结果三**”。`
- 分组名称用 `**加粗**` 标记，不另加引号。直接列出的完整结果名称用中文双引号，其中概念用 `**加粗**` 标记。
- 括号内并列结果用顿号分隔，组间用分号分隔；直接列名时用顿号，“和”或“或”前不再加顿号。
- 数量只加粗数字，不加粗量词。
- 同一概念只强调首次出现；共享的结果维度也要明确标记。

## 3. 摘要：最终得到什么

**模板**（一个自然段，尽量简短地交代每个最终变量和总数；允许按共同维度归纳，算法、时期差异和使用限制写入各自栏目）：

**按结果维度分组：饮酒模块**：

**按结果维度分组：运动模块**：

```markdown
## 摘要导读

本主题定义 **25** 个变量：**是否进行至少 10 分钟活动**（①高强度、②中等强度、③步行、④任一类）；**每周天数**（⑤高强度、⑥中等强度、⑦步行）；**每日时长档**（⑧高强度、⑨中等强度、⑩步行）；**每日估计分钟数**（⑪高强度、⑫中等强度、⑬步行）；**每周估计分钟数**（⑭高强度、⑮中等强度、⑯步行、⑰中高强度）；**活动主要目的**（⑱高强度、⑲中等强度、⑳步行）；**综合活动指标**（㉑最高强度、㉒每周估计体力活动量、㉓休闲活动每周估计活动量、㉔工作活动每周估计活动量、㉕是否以体育锻炼为主要目的）。
```

## 小book任务

- 入口：交付结构、调查设计和本主题的采用方式已经明确。
- 输入：本次实际结果、调查设计及帮助理解本次选择的必要背景。
- 操作：按下方选择顺序和基础写法；不把单变量注意点和执行过程搬来。
- 产出：实际提示的独立段落，或约定省略句。
- 验收：必要背景和本次选择讲清楚，无关信息和重复说明已删除；显示交生成器。
- 失败：未知事实回有关来源；已知事实难懂留本任务，不据此重开全库探索。

## 6. 小book：理解和使用本主题所需的补充说明

用必要的背景把本次数据特点和选择讲清楚，讲清楚就停。

**内容要求**：

按以下顺序选择内容；没有需要补充的事实时不增加条目。

1. 先说明记录单位和调查设计：一行代表什么，不同时期是否追踪同一批人。人—年长格式说明每行是一个人在某年的记录；系列横断面调查说明各年分别抽样。
2. 再说明本次多个结果共同使用时需要知道的具体差异。写清涉及的结果、时期或对象，差异是什么，以及会怎样影响理解、比较或汇总。不能只写“影响可比性”而让读者自行猜测。
3. 有多个版本或处理阶段且需要帮助读者理解本次选择时，说明必要区别及采用方式。校正事项可说明原值、校正值分别是什么、涉及时期及本次保留或采用哪些。

直接说明交付结果，不延伸出无关的去重或统计建议。
- 校正提醒按上项处理；其他只影响单个变量的提醒放在该变量的“注意点”。常规适用人群和共同局限按[信息取舍](../stages/03-copy.md#解释性文案的信息取舍)留在 R 注释，不搬入小book。

**表达要求**：

- 每条先用一句短句点明读者需要知道的事实，再补充理解它所需的背景、条件或具体影响。首句不重复其他条目已讲清的要点。
- 一条围绕一个要点，句子按[通用表达](../stages/03-copy.md#通用表达)书写。
- 具体例子比抽象结论更清楚时，可用代表性例子说明区别和本次选择，不逐项重复列举同类情况。简洁以讲清楚为准，不为压缩篇幅删去必要背景。
- 公式、系数、赋值步骤和程序操作留在 R。涉及样本纳入范围或结果可比性时，保留必要的时期、对象和例外。文件保存和执行记录不放入小book。

- 不堆砌与本次理解和使用无关的背景、历史经过或泛泛的风险提醒，不设想可能的问题或补充通用分析常识。
- 例如，“调查样本会变化”“名册有记录不等于参加访谈”，只有查清与本次结果的具体关系时才写，不能代替尚未查清的事实；但不能因此删掉必要的记录单位、长宽格式和纵向或横断面设计说明。
- 没有需要补充的信息就省略，不为了凑提示另找问题。

同一信息已在前文或其他条目讲清，且没有需要补充的内容时，不再重复。确需补充时，只写新增的事实及影响，不换个说法重述已有结论。不汇总各变量的注意点，不搬入探索过程或 QA 计数。只写实际需要说明的事项，不凑类型或数量。

**格式要求**：

- 二级标题为“小book提示”。
- 每条一段，条目之间空一行。生成器按顺序显示 `1. `、`2. `，只有一条也编号；文案已有编号时，生成器先识别编号，再统一显示。
- 首句以中文句号结束，不加粗；生成器将首句显示为数据库主题色，后面的解释使用正文色。
- 编号在左，换行后的文字与该条正文起点对齐，不与编号对齐；颜色与缩进由生成器统一处理，文案不手写样式。
- 没有需要单独提醒的事项时，正文写固定句“本主题没有需要单独提示的主题级边界”，生成器会省略卡片。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#6-小book理解和使用本主题所需的补充说明)。


**模板**（有必要的数据结构、调查设计说明或具体发现时替换省略句；下列实例不是每篇都要凑齐的提示类型）：

```markdown
## 小book提示

本主题没有需要单独提示的主题级边界
```

每条独立成段，多条之间空一行。可以按以下示例写编号；固定生成器负责最终顺序编号和缩进，只有一条也显示 `1. `：

```markdown
1. {用短句点明本条事实，不重复其他条目的要点。}{补充理解本次选择所需的背景、区别或条件，按需用具体例子讲清；不展开计算或赋值步骤。保留必要的时期、对象和例外。}

2. {另一项确实值得补充的事实，没有则删除本条。}{必要解释；不重复上一条结论，不加入文件保存或程序操作。}
```

首句不加粗，生成器自动使用数据库主题色；后面的解释保持正文色。编号独立在左，换行与正文起点对齐，不靠空格排版。

## 7. 参考资料说明

**目的**：让读者找到实际采用的资料，并知道它支持哪部分定义。

**内容要求**：

- 只列实际支持公式、计分、分类、阈值或解释限制的已核实材料。
- 每条简述材料的实际用途，不重复正文中的方法、选择理由或处理细节。
- 没有实际使用的方法资料时省略本节，不为填满栏目补文献。
- 普通应用文章留在探索记录；已在问卷展示的调查事实不再重复列作方法文献。
- 检索失败、访问过程和检查结论留在探索或执行记录。本节只说明实际采用的资料及其用途。

**写入方式**：在二级标题“参考资料说明”下，每份材料单独写一行，包含材料名称、链接和简短用途。材料名称写明实际项目及年份、调查周期或版本，让读者能区分各份材料。没有链接时给版本和页码，不编造地址。

**生成方式**：生成器按材料顺序统一输出`> 1. `、`> 2. `，每条一行，条目之间不空行。文案无需手写编号；已有编号由生成器整理，不重复编号。

## 组装任务

- 入口：本次范围内正文和必要展示字段已完成。
- 输入：唯一完整稿、当前来源记录、已有有效结论与本次范围。
- 操作：按下方展示顺序组装，再执行入口的检查与交接。
- 产出：完整文案和实际检查结果；只读任务只交发现。
- 验收：改动范围正确，检查证据对应当前文件；通过不代表程序未检查的语义也通过。
- 失败：按表达、事实、实现或显示问题返回相应任务/阶段，不重启未变全流程。

## 1. 文案组成与顺序

下表是`文案.md`的展示顺序，不是业务决策或编写顺序。有条件的部分按实际情况写，不为凑齐栏目增加内容。

| 栏目 | 保留的文字内容 | 展示条件 |
| --- | --- | --- |
| 标题 | 这是哪个数据库、什么主题 | 必填 |
| [摘要导读](#3-摘要最终得到什么) | 定义了哪些变量、共多少个 | 必有 |
| [关系树](tree.md#关系树) | 变量名称、分组、组成及计算关系，必要的取值或单位 | 能清楚表达关系时使用 |
| [定义依据](basis.md) | 文献定义的分歧、本次选择及理由 | 默认不展示；仅复杂定义的多个文献出处存在定义不一致时展示，见[依据展示判断](../stages/03-copy.md#依据展示判断) |
| [问卷](questionnaire.md) | 原题、选项、必要跳转；简短的问卷设计或时期变化说明 | 定义依赖跳题、多题关系，或需要原题帮助理解时展示 |
| [定义卡片（Criteria）](#5-criteria每个变量怎样得到) | 定义：表示什么；定义逻辑：怎样构建；分类：有效取值；注意点：必要的含义或口径提醒 | 每个最终变量都有；无注意点则省略该项 |
| [小book提示](#小book任务) | 数据记录单位、调查设计、具体差异及理解本次选择所需的背景 | 有实际需要补充的内容时展示；没有则使用约定的省略句 |
| [参考资料说明](#参考资料任务) | 材料名称、年份或版本、链接、简短用途 | 有实际采用的资料时展示 |

生成后的笔记会把小book移到问卷之后，并自动加入图表和附件；这些不用手写进文案。
