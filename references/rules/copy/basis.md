# 定义依据任务

入口：已按 [依据展示判断](../stages/03-copy.md#依据展示判断) 决定展示。
输入：已核实的标准/资料、适用对象和时期、已确认的取舍与理由。
操作：选择统一标准、单一可用依据或实际方案比较的写法；区分资料建议与项目自行处理，按下方要求说明。
产出：定义依据正文；已决定省略则不填空栏。
验收：来源支持其实际说法，与已定方案及实际展示的Criteria一致，不为表格虚构方案或理由。
失败：资料或取舍未定回来源；已定内容的表达问题留本任务。

### 依据内容与格式

说明本次采用的定义；有比较时，先讲清差异，再说明选择。可放在表格的“本次处理”列或表后的必要说明中，不要求另写重复段落：

1. 写明采用哪套方案，或从哪些方案采用哪些规则。
2. 选择或调整的理由紧跟对应选择，说明实际收益和代价。
3. 说明数据限制导致的替代、项目自行确定的处理，以及适用范围。
4. 替换项目、改变阈值或另定缺失处理时，明确列出改动；不能声称完全采用原标准。

依据和选择按[通用表达](../stages/03-copy.md#通用表达)书写，并保留以下信息：

- 采用资料中的建议时，写清哪份资料建议什么、为什么这样建议，以及本次采用什么；不省略来源，写成项目自行推导的结论。
- 本项目另作的选择单独说明，不与资料原有建议混写。
- 同一处理只适用于部分时期或对象时，在对应说明中讲清关键区别，不让读者从各期问卷或变量条件中自行拼出原因。
- 条件和例外跟随对应做法，不为缩短句子省略，也不重复展开无关流程。

不能用“文献权威”“感觉更好”代替选择理由。
不能只写“参考多篇文献”就直接给出算法，也不能把拼接后的方案称为原文标准。

| 信息 | 保存位置 |
| --- | --- |
| 方案差异、最终取舍及对应理由 | 本节 |
| 共同适用范围和局限 | 本节集中说明一次 |
| 逐变量公式、阈值和计算边界 | 完整模式放在 Criteria，并与本节一致；缺失说明按[定义逻辑](core.md#5-criteria每个变量怎样得到)规定的范围填写。模块展示例外按[统一规则](../stages/03-copy.md#模块展示例外)处理 |
| 已核实的比较来源 | 比较表就近标注 |
| 原文疑点的具体证据、具体方法出处 | 参考资料说明；不重复整张比较表 |

**格式要求**：二级标题用“定义依据”，放在摘要导读之后、问卷之前。

本节优先用能清楚表达信息的图表，不限于多套方案比较。并列的依据、选择或方案差异用表格；组成、依赖或分支关系用简洁的关系图。图表不能更清楚表达时再用纯文本，必要解释可紧跟图表。图表已说明的内容不再用段落重复；不为使用图表补造方案或理由。

只有一套依据时，也可用“注意事项｜详情/依据｜本次处理”整理；每行只写一个事项，用短语作行名。详情/依据只保留影响本次选择的事实或文献做法；没有需要填写的内容时写“-”，不把原始数据的做法冒充本次选择的依据。处理列写采用什么及必要条件，不重复 Criteria 的具体算法或实现代码。
比较表列出方案与来源、主要计分方法、影响选择的关键差异。
只有人群、时期、题项或缺失处理影响本次选择时，才将其列入表格，不要求每行穷举。
需要比较但原文未报告的内容如实说明，不能补猜。

本节规定正文内容和位置。
新结构的读取、生成和显示兼容检查按第5步执行；文案检查通过不等于成品正确显示。
