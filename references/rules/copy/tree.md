# 关系树任务

入口：已满足 [树使用条件](#关系树)，或用户指定修改树。
输入：方案中已确认的输出、组成、中间量、计算与分类关系，及已明确的定义逻辑。
操作：先选下表适用结构，再写对应节点、关系和 meta，最后使用语义标记；模板只表达已定关系。
产出：可解析且与结果一致的树；不由树增加变量或改变定义。
验收：语义判断关系和范围；程序检查标记与实际可检查对应；显示效果归第5步。
失败：关系未定回来源；标记或排列问题留文案；正确标记的转换/显示问题回生成。

## 关系树


**内容要求**

1. 选择结构。

同一主题默认用一棵树。主题内的内容分组放在树内分支，不各设标签。只有包含两个或更多独立、平行的主题定义时，才分别画树并设置标签。

| 要说明的关系 | 优先结构 | 内容安排 |
| --- | --- | --- |
| 同一主题包含分项、总分、分类或辅助结果 | 主题为根 | 组成、总分、辅助结果并列；分类放在对应总分下 |
| 多个并列结果按内容分组 | 主题为根 | 内容组下列出具体结果；组名不计为输出变量，不添加不存在的计算关系 |
| 一个综合结果有多层组成 | 综合结果为根 | 依次展开领域和分项；在实际计算发生的层级说明算法 |
| 少量条目合成或划分结果 | 条目 → 计算 → 结果 | 展示输入、运算和输出；分类接在对应结果下 |

多种结构都适用时，选择能完整说明关系且重复最少的一种。不为套模板增加层级。

2. 写清节点与计算关系。

- 最终结果使用已确定的名称。
- 主题根节点表示主题，不计为输出变量；综合结果根节点表示实际输出结果。
- 展开组成的具体子项，不用条目数量代替子项名称。
- 每个合成或分类结果都要说明组成和计算关系。
- 同一组分项产生多个结果时，共同条目展开一次；各结果写清选用哪些条目、怎样计算。
- 同名领域使用不同指标时，分别写清组成。是否属于同一跨期结果，按[已定方案](../stages/01-source-plan.md#跨期结果合并)处理，不只凭名称决定。
- 需要展示中间计算量时，注明其不单独输出。摘要总数只统计最终输出变量。
- 来源有助定位时，在对应节点旁写原始变量或题号。来源名称不另作计分成分。
- 只写已确定的算法。不把占位提示或“待确认”写入正式树。

3. 每个展开的计分子项都在名称旁填写 meta，保留取值、范围或单位；具体内容按节点含义选择。

| 节点表示什么 | meta 写什么 | 示例 |
| --- | --- | --- |
| 最终定义变量 | 最终取值、范围或单位 | `（0/1）`、`（0–8 分）` |
| 中间计分项 | 计分后的范围或单位 | `（0–3 分）` |
| 原始回答或测量值 | 原始选项、范围或单位 | 回答确为是／否时写 `（是/否）`；体重写 `（kg）` |

- 节点名称、meta 和计算关系须表示同一内容。不得混用原始回答与计分结果。
- 需要提示反向计分时，在对应子项旁注明。

4. 按适用范围放置说明。

| 说明适用于哪里 | 放在哪里 |
| --- | --- |
| 整棵树的时期 | 首行标题旁；每棵树分别注明 |
| 整棵树的人群、年龄、完整性条件或得分方向 | 标题下、分支前；没有则省略 |
| 某个分支的条件、时期或来源差异 | 对应分支旁；不要扩大到整棵树 |
| 完整重编码、补值步骤、质量核查 | Criteria 或代码，不放进树 |
| 问卷进入条件和跳转 | 对应问题块，不由关系树代替 |

共同条件不作为组成子项，也不代替各计分子项的取值说明。树中只保留理解关系所需的简短条件。

**格式要求**

1. 每棵树独占一个代码围栏。起始行写成“```text 简短标签名”。
2. 标签使用实际主题或独立量表的简称。只有一棵树也写标签。
3. 树内不插空行。不同围栏之间留一行空白。
4. 时期使用半角方括号，如 `[1993-2022年]`。取值、范围和单位使用圆括号。
5. 用以下标记说明文字作用。新写或修改的树须标记最终变量和 meta；涉及组成或计算说明时使用对应标记。

| 文字作用 | 写法 |
| --- | --- |
| 最终定义变量 | `[[result:结果名称]]` |
| 组成部分或中间计分项 | `[[component:名称]]` |
| 计算关系、阈值或条件 | `[[relation:说明]]` |
| 取值、范围、单位、时期或来源 | `[[meta:说明]]`；时期示例：`[[meta:[1993-2022年]]]` |

- 不嵌套标记，不跨行标记，不写颜色或 HTML。
- 主题标题不因位于根节点就标为 result。
- 树线和箭头由生成器标记，不按缩进推断节点身份。
- 用半角空格保留缩进，按可见字符的显示宽度对齐，不用 Tab 或字符个数估算。
- 右侧汇合时，上下转角和中间连接点必须在同一竖列。

显示样式和未修改旧树的显示兼容由[第5步关系树显示](../stages/05-generate.md#关系树显示)统一规定。写作只提供上述内容和语义标记；新写或修改的树仍遵守本节格式。

**模板与实例**：[查看关系树模板](../../../templates/reader-copy.md#关系树模板)。



选定结构后，从 [关系树模板](../../../templates/reader-copy.md#关系树模板) 只取对应骨架或实例：并列结果按内容分组、同主题多种结果、多层综合结果、少量输入合成。没有右侧汇合时，不加载汇合示例。基础语义标记已在本任务，不必为标记语法读完整实例集。
