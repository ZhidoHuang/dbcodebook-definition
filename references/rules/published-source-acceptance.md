# Scoped Published Sources With Unknown Generation

本接口仅用于用户明确选择沿用已定位发布字段、并接受其生成机制尚未知的特定方案。常规来源探索和问卷证据要求不变；缺证据、两个代理推测一致、记录中自填 approved，均不能启用本接口。

## 独立记录两类事实

- `published_origin_unknown` 表示字段生成、问卷关联及记录活动仍未知；不得改写为 questionnaire、not_applicable 或原卷路径已证。
- `operational_assignment_review` 必须由实际逐人核验支持：状态 exhaustive、未分类人数0、无重复个人赋值，各结果×实际输出挂载期的互斥分支之和等于该期个人分母。此处0不意味着来源机制已知。
- `published_assignment_closure.unexplained_count` 表示操作性未分类数；逐人分区已证全覆盖时如实为0，同时 `generation_origin=unknown`。不能因为生成机制未知把已证为0的赋值未分类数强制写null。
- 输出挂载期和源字段可用期分别声明；值来源与挂载位置的依赖分别声明。跨期个人结果不能以逐波来源行数代替。
- `questionnaire_paths_closed` 保持 null；以 `operational_assignment_paths_closed=true` 表示已选方案的赋值覆盖。仍未解决且会改变结果的歧义继续阻断，不能当成来源机制未知而豁免。

## 授权及范围

主题过程目录保存政策与实际授权依据、来源事实、逐人分支证据。可信执行配置通过 `published_source_policies` 显式登记过程政策的路径和 SHA-256；不登记就拒绝。来源记录还须绑定同一政策路径、政策哈希与授权哈希。共享规则仓库只保存接口代码和本说明，不保存主题政策、包哈希、授权文件或本机证据。

政策精确限定数据库、主题、用途、完整字段身份、导出别名、源期、输出挂载期、结果、原包与输入文件指纹、计数证据及必须披露的内容。每次执行核对实际文件内容；改主题、字段、期、包、用途、计数或授权必须取得匹配的真实授权绑定，不能复制旧接受结构通用放行。

过程JSON、自填authority_kind或任意执行Config均不能充当原始人类授权。当前接口只读核验宿主原生sessions目录中的真实question-reply：原始行SHA、session身份、消息ID/时间、user角色、保留元数据以及问题/回答全文均须一致；路径通过操作系统用户目录定位，不能用CODEX_HOME覆盖成过程目录。当前仅支持已核实的原生question-reply形式；其他平台/授权形式不支持时停止，不猜测批准。

该核验只证明真实用户说过相应原话，不能机械证明任意新政策的全部语义获其批准。执行前强制检查当前过程execution_report的独立角色“发布来源语义授权复核”：真实完成、非isolated、pass且绑定精确source、policy、授权依据及三个原包成员。再从该注册reviewer的宿主原生会话读取明确机器块，核对同一policy/source/用途/授权证据和原答行SHA，要求分别说明用户直接授权、技术解释及无未决决定。过程JSON、自填Config、伪造report输入哈希或“待审查”提示不能替代这条硬门禁。实际机器块的tag为 `dbcodebook-published-source-scope-review`；字段和一致性由 `published_scope_review.py` 校验。缺任何真实审查链就失败；改purpose或policy，即使原答真实也自动失效。原公开R复核及正式runner门禁另外保留。

哈希只能锁定内容，不能证明字段来源性质。当前原型仅接受明确标注的隔离部署，不能把隔离政策直接复用为生产部署。相对证据与同目录policy路径按实际过程目录解析；`formal:成员名` 只通过执行配置的正式根、数据库目录及实际编号主题目录定位，同一个来源文件搬迁时不嵌入旧过程根。

所有来源组、身份、别名、源期、结果、输出挂载期、披露及分支契约必须非空且唯一；来源期覆盖必须完整使用声明身份，每人的锚点分母总和等于实际个人全集。记录中的分支条件、结果和证据定位必须与精确政策逐项一致，不能只锁分支ID和计数。

## 产物和执行

每个最终结果的文案“注意点”，以及笔记和定义 HTML 中该结果本身的 Criteria 单元格，均须实际展示政策规定的未知来源披露；摘要、另一结果或 detail 单元格的披露不能代替。文案保持纯文本。成品的锁定披露是一个不含嵌套样式子元素的普通渲染段落；用本地离线浏览器核验其绘制区域、逐字几何和遮挡。当前保守规则要求不透明、字号至少12px、文字/背景对比度至少4.5，拒绝绝对/固定/越界定位、变换、滤镜、遮罩、动画及隐藏/不可见文本；滚动后所有非空字符必须在可访问视区且命中自己的文字元素，不能被覆盖层遮挡。此模式额外依赖Python Playwright和本机Edge（Windows）或可用Chromium（其他平台）；禁止联网请求和页面脚本，外部样式表或缺少浏览器运行时无法建立可见性时明确失败，不退回仅textContent包含检查。成品可读性报告单列未知发布来源和操作性赋值状态，不能显示为问卷路径已证。

runner 在文案、来源及渲染检查前传递同一个显式执行配置。原独立探索、公开 R 复核、实际生成与发布门禁保持；功能夹具或原型测试通过不构成正式生成或发布授权。

遮挡检查不只看elementFromPoint：即使绘制层设置pointer-events:none，与披露段落相交的非祖先/非后代布局区域也会保守拒绝，包含可计算的阴影/描边扩展。复杂伪元素、滤镜和重叠布局不在此模式的普通段落支持范围；仅放行共享渲染器中远离披露区的标准小折叠箭头。普通静态渲染正例、隐藏/负坐标/透明度/低对比及不可交互覆盖层均须实测。此检查是声明范围内的保守机器检查，不等于对任意CSS绘制效果的完备视觉证明；正式独立验收仍须查看成品。

配置路径沿用skill_config约定：formal_root相对配置文件所在目录解析，并展开环境变量和用户目录；不能相对调用进程的cwd解释。绝对路径行为不变。
