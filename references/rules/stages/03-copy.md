# 3. 文案写作

根据已经确定的定义方案、官方材料和实际数据，在一份`文案.md`中完成下列内容。本页说明各部分的目的、内容要求和格式；[文案模板与实例](../../../templates/reader-copy.md)按相同顺序展示写法。完整写作前读取这两份文档；局部修改时读取两份文档中对应的部分。

## 1. 文案组成与顺序

按下表顺序填写`文案.md`。有条件的部分按实际情况写，不为凑齐栏目增加内容。

| 组成 | 让读者明白什么 | 何时填写 |
| --- | --- | --- |
| 标题 | 这是哪个数据库、什么主题 | 必填 |
| 摘要导读 | 定义哪些内容，共多少个变量 | 必填；结果关系按需另用关系树展示 |
| 定义依据 | 有哪些适用标准，为什么采用本次定义 | 采用量表、诊断、分类或综合指标的标准时填写；按下文决定展示一套标准还是比较多套方案 |
| 原始问卷 | 帮助理解结果取值所依赖的题义和提问条件 | 定义依赖跳题、多题关系，或原题能消除关键歧义时展示相关部分 |
| Criteria | 每个变量的含义、取值方法及必要限制 | 每个最终变量都填 |
| 小book提示 | 多组结果或整个主题使用时要注意什么 | 有这类提醒时填写；没有则使用约定的省略句 |
| 参考资料说明 | 定义方法有哪些依据 | 有实际使用的方法资料时填写；没有则省略该节 |

生成后的笔记会把小book移到原始问卷之后，并自动加入数据库目录入口、图表和附件；这些不用手写进文案。

通用写法：用读者能理解的话说明具体事实，名称已经清楚就不再释义。同一信息放在最合适的位置；再次提及时应有不同用途。全篇名称的对象、方向、时间和单位保持一致。初稿依据本次已确认事实，不照抄旧稿；来源不明、方案未定时先解决事实问题，不在写作时自行增加口径。

通用格式：使用Markdown，不手写HTML或CSS。正文中的变量名和代码用反引号；原始问卷的题目标题不加反引号，由生成器加粗显示。数字与量词间留一个半角空格，百分号紧贴数字。

### 写作前先判断两件事

这两项判断分别决定问卷如何分组、定义依据如何介绍，不需要给主题增加新的分类名称。

| 判断 | 怎样判断 | 怎样写 |
| --- | --- | --- |
| 结果之间是什么关系？ | 区分共同测量同一概念、多个结果并列，以及不同成分共同构成综合结果。人口学的多个并列概念不因此成为综合指标；不能只按题目数量判断。 | 复杂综合结果按实际构成画树；并列结果不强制画树。问卷先判断是否需要展示；只有一组问题时按时期组织，多组提问程序或时期变化不同的问题，先按实际题组分块，再各自设置时期标签。 |
| 是否有公认且适用的统一定义标准？ | 根据已核实的指南、原始方法或技术资料判断，并核对适用人群、版本和数据是否匹配。只找到一篇论文，或多篇论文引用同一框架，都不足以证明具体计分统一。 | 有统一标准时展示该标准及本次实现；主要文献在成分、计分或阈值等方面存在实质差异时，对比主要方案，再说明最终采用的定义。 |

使用文献和问卷已有的概念名称。这里的分组是为了让读者理解，不得自行发明概念、量表名称或标准，也不把本次内在能力的成分和算法套到其他主题。

## 2. 标题

**目的**：让读者识别数据库和主题。

**内容要求**：主题名称准确覆盖实际定义，不扩大范围，也不堆列所有变量。中文与英文含义一致。

**格式要求**：一级标题，使用“数据库 — 中文主题（英文主题）”，不加主题序号。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#2-标题)。

## 3. 摘要：最终得到什么

**目的**：让读者知道本主题定义哪些内容，共多少个变量。

**内容要求**：

只介绍定义内容和变量总数。有综合结果时，先介绍综合结果及其分类，再介绍分项；多个并列结果可逐项列出，也可用基本人口特征、教育等具体内容名称概括，不用“若干指标”等空泛说法。

结果关系交给下面的关系树；具体含义、对象、时期、单位、得分方向及赋值和计算条件写在对应变量的 Criteria；跨变量或整个主题的使用限制写在小book。摘要文字不再展开这些说明。关系树不适用时无需添加，Criteria仍须独立讲清变量的含义和取值方法。

**格式要求**：二级标题为“摘要导读”。摘要文字写成一个自然段，不按内容组拆成多段，不用表格或列表罗列结果；需要关系树时另接在这一段之后。结果名称用中文双引号，概念用`**加粗**`标记；数量只加粗数字，不加粗量词。同一概念只强调首次出现，共享的结果维度也要明确标记。

**构成或分类关系树**：复杂综合定义在摘要文字后展示“综合结果 → 成分 → 分项”的实际构成关系；原题对应有助于定位时，在分项旁注明题号。没有中间层就不虚构一层。其他主题有多层结果关系时可画树，简单单一关系在对应变量的 Criteria 中用文字说明，不写回摘要导读。节点使用已确定名称，标明相加、平均、加权或分类关系及必要条件，不把辅助资格题画成计分成分，不在树里展开原题清洗和缺失处理。问卷跳题流程放在相应问题块，不能用构成树代替。

使用无语言或text代码围栏，保留树线及前导空格；现有渲染器负责显示样式。右侧汇合时，上下转角与中间连接点须在同一竖列；按字符的显示宽度留半角空格，不按字符个数或用 Tab 估计缩进。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#3-摘要最终得到什么)。

### 定义依据：先说明标准，再说明本次采用什么

正文位置为摘要导读之后、原始问卷之前，二级标题用“定义依据”。直接保留原始事实或进行简单计算、没有标准选择问题时，可省略本节。

- **有公认且适用的统一标准**：介绍这一套标准的名称、来源和版本、适用人群、组成及计分或判定方法，再说明本次使用的时期和数据对应。无需为凑比较而罗列其他方案。若本次替换了项目、改变阈值或另定缺失处理，应明确写出改动，不能声称完全采用原标准。
- **有多个实际可比方案**：主要文献在组成、计分或阈值等方面的差异影响本次选择时，用对比表列出已核实方案。比较实际有关的来源和版本、组成与题项、计分方向与范围、权重或阈值、适用人群和时期、缺失处理；没有明确报告的内容写“未报告”，不能补猜。只有一套可用依据时，直接说明其内容、适用性及采用理由，不为凑比较添加方案，也不把它称为公认统一标准。
- **对比后明确本次最终定义**：写清采用哪套方案，或从哪些方案采用哪些规则；说明选择依据、受数据限制的替代、项目自行确定的处理及适用范围。不得只写“参考多篇文献”后直接给出算法，也不得把不同论文拼接后的方案称为原文标准。

这里让读者看清方案差异和最终取舍；逐变量的完整公式、阈值及缺失处理仍在 Criteria 中写清，并与本节一致。比较表就近标注已核实来源，参考资料说明补充具体方法出处，不重复整张比较表。此要求规定正文内容与位置；新结构的读取、生成和显示兼容检查按第5步执行，不能把文案检查通过当作成品已正确显示。

**模板与实例**：[定义依据](../../../templates/reader-copy.md#定义依据)。

## 4. 原始问卷：调查实际问了什么

**目的**：让读者看到定义所依据的实际问题和提问程序。

**何时展示**：先看本次定义怎样得到。直接采用已发布的性别、年龄、官方分类，或由家庭人数等于1判断独居，通常在定义逻辑说明来源和取值即可，不展示原始问卷。需要结合前置回答、跳题或多题关系才能判定结果，或原题含义会影响结果解释时，只展示相关题目及理解它所必需的条件。混合主题按题组取舍；都不需要时，省略整个“原始问卷”部分，不写省略说明占位。研究时仍核实必要问卷和官方材料，证据保留在探索记录，不因正文省略而删除。

**内容要求**：

| 组成 | 写什么 |
| --- | --- |
| 题组分组 | 只有一组问题时直接设置时期标签。多组问题的提问程序或时期变化不同、需要分开说明时，先按实际题组分块，再各自设置时期标签。构成树表达结果关系，问卷题组表达实际怎样提问，二者不必逐层对应。题组名称沿用已有概念，不按每个计算结果或每道题重复建块。 |
| 时期分组 | 在每个问题块内独立比较时期：题义、选项含义、适用人群、回顾期和提问路径一致的时期合并；实质变化的时期另列。只有题号或编码写法不同、含义和路径不变时，说明对应关系即可。一个成分发生变化，不迫使其他成分一起拆分。不能在整篇前面集中共同题、后面统一补各成分的变化题。 |
| 问卷设计／问卷设计变化 | 每个模块的首个时期组介绍调查对象、提问内容和顺序；后续时期组说明变化，并完整呈现该时期理解本模块所需的问题和路径。展开任何一个时期标签后，都能独立读懂本模块，不要求读者切到另一标签寻找题干、选项或前置条件。不同模块之间的区别不写成跨期“设计变化”。 |
| 原始问题 | 展示定义所依据的完整中文题干、选项、单位及必要的提问说明，包括影响进入条件的上游题和相关跳转。题组内问题较多时，可按实际内容用小标题分块；已经分清的题组不为凑层级重复分块。同一时期标签内相同选项只展开一次，明确哪些题共用；各题不同的进入条件和跳转分别保留。不能跨标签省略必要选项。 |

**格式要求**：

- 单一题组的标题：二级“原始问卷”→三级适用时期→四级设计说明和题目标题；必要的上游题／目标题分组用四级标题，题目标题用五级。
- 多个独立题组的标题：二级“原始问卷”→三级题组名称→四级适用时期→五级设计说明。没有内部小标题时，题目标题用五级；需要内部小标题时，小标题用五级，其下题目标题用六级。题目标题按下文选用原问卷标识，小标题使用内容名称。每个题组有自己的一组时期标签；不机械复制构成树的领域、成分和分项层级。
- 同一模块首次展示用“问卷设计”；因跨期变化另列时用“问卷设计变化”。连续时期可写 `Wave 1–3`，不连续时期逐项列明。
- 每题优先使用原问卷标注的变量名作为标题；原问卷只有数字题号时，保留题号，并注明已核实的对应数据变量名。跨期标识不同的，就近说明对应时期和关系，不自行编造或替换标识。
- 题干不加引号；设计说明中概括的问题用中文双引号。仅能核实题意、无法取得完整原题时，在设计说明中写“题意概括：”及“未取得完整原题的原因：”，不编造题号或选项。
- 选项用短横线，保留编码和标签。共用选项的说明放在首次完整展开该组选项的题目下。连续题号可写 `DB001–DB015 的选项设置相同，该范围内的后续题目不再逐一展开选项。`编码写法分期变化时，用 `原问卷选项编码（适用时期）：编码=标签；编码=标签。` 集中说明，题块只列共同标签，导出解码值另说清楚。
- 有进入条件才写“适用对象：”，写明判定题及回答。多题共同决定时，写清各题回答及组合关系，如“同时满足”或“满足任一”。仅题号不足以说明对象时补题义。
- 跳转写在对应题目下：已展开选项时，紧跟该选项写 `→ 跳至 题号`；选项已共用、不再展开时，写 `跳题说明：回答“1 没有困难”时，跳至 DB004。`，不让读者回看另一题的跳转。整组作答后的检查点放在该组末题后，写清触发条件、组合关系及去向，不提前挂到首题。不再返回本主题时写 `→ 结束该主题`，顺序作答不补提示。
- 同一模块有多条条件分支、仅逐题文字难以看清路径时，在对应时期的相关题目后补简短分支流程图，标明判定题、回答和去向。使用text代码围栏；图不能代替完整题干、选项和跳题说明。跨模块的必要前置条件在本模块就近说明。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#4-原始问卷调查实际问了什么)。

## 5. Criteria：每个变量怎样得到

**目的**：让读者理解每个变量，并能据此判断一条记录该取什么值。

**内容要求**：每个最终变量填写一组，名称与方案一致；先写组成变量，再写综合变量。赋值、补值及计算条件放在相关变量的“定义逻辑”中，不在 Criteria 开头另放共同处理段落，也不用“符合共同条件”等引用代替实际条件。

| 栏目 | 内容 |
| --- | --- |
| 定义 | 用一句话说明变量表示什么，带上必要的对象、回顾期或单位 |
| 定义逻辑 | 说明所用信息、如何得到取值及必要特殊处理，具体写法见下方 |
| 分类 | 列出最终编码与含义；数值变量说明类型和单位。使用方案确定的类别，不拿原问卷编号替代结果编码；实际分布留在QA |
| 注意点 | 写使用时必要的换算依据、时期差异或比较限制，不重复计算步骤；没有就省略 |

定义逻辑把所用信息和取值方法连着写，特殊处理接在后面；只写实际涉及的内容，不另拆固定栏目：

1. **说明原始信息怎样成为本变量。** 原有含义、分类或数值不变时，说明保留什么；重新分类时，写清哪些回答归入哪类；换算或合成时，写清计算方法、单位和必要权重。仅统一代码或标签时，说明保留的含义，具体取值放在“分类”，不重复罗列整套对应。使用已定义变量时直接接着计算，不重复其生成过程。
2. **范围说明放在对应方法旁。** 涉及不同对象、时期或来源时，就近写清谁适用、哪期用哪个来源，以及必要的选用顺序，不用“按当期题义对应”“依口径处理”代替具体说明。
3. **特殊处理写清条件和结果。** 本变量涉及补值、缺项计算或折算时，直接写“满足……时，本变量记为／按……计算”；多题共同触发时写全回答及组合关系，必要时区分不能这样处理的情况。普通未回答且没有另作处理，不专门补写“保留缺失”。

所有条件都来自已确定方案，原始回答用真实选项。调查提问流程放问卷；使用限制放注意点；防报错的程序细节留在代码。一句能说清就写一句，不为完整形式增加背景或步骤。

**格式要求**：二级标题“Criteria”；三级标题用实际变量名；四级标题依次为“定义”“定义逻辑”“分类”“注意点”。定义逻辑有多项时用①②③；分类用短横线，取值、编码及类别用方括号。没有注意点时删除整个栏目。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#5-criteria每个变量怎样得到)。

## 6. 小book：跨变量或整个主题的使用限制

小book说明多个结果共同使用或整个主题使用时，哪些具体情况会影响解释、比较或汇总。只影响单个变量的提醒放在该变量的“注意点”；计算或缺失处理规则放在相关变量的“定义逻辑”。

每条提示从本主题已核实的事实出发，例如跨期题义或项目范围变化、抽样安排、记录单位和重复记录。明确涉及的结果、时期或对象，写清“具体情况或差异是什么，会怎样影响使用”，不能只写“存在差异”“谨慎使用”等通用提醒。本次确实作了处理时，再说明处理结果。

同一使用限制已在前文讲清，且没有需要补充的共同使用影响时，不再重复；不汇总各变量的注意点，不搬入探索过程或 QA 计数。只写实际需要提醒的事项，不凑类型或数量。

二级标题为“小book提示”。多条提示用 `1. `、`2. ` 编号，每条一段，条目之间空一行；只有一条不必编号。没有需要单独提醒的事项时，正文写固定句“本主题没有需要单独提示的主题级边界”，生成器会省略卡片。

## 7. 参考资料说明

**目的**：说明采用的方法或解释限制有什么依据，哪些是本项目另作的选择。

**内容要求**：没有实际使用的方法资料时省略本节，不为填满栏目补文献。只列实际支持公式、计分、分类、阈值或解释限制的已核实材料。每条说明材料讲了什么、支持本主题哪部分；必要时说明它没有规定、由本项目决定的处理。普通应用文章留在探索记录；已在问卷展示的调查事实不再重复列作方法文献。

**格式要求**：二级标题“参考资料说明”。使用`> 1. `逐条独占一行，条目之间不空行。材料名链接到已核实地址；没有链接时给版本和页码，不编造地址。
