# 3. 文案写作

根据已经确定的定义方案、官方材料和实际数据，在一份`文案.md`中完成下列内容。本页说明各部分的目的、内容要求和格式；[文案模板与实例](../../../templates/reader-copy.md)按相同顺序展示写法。完整写作前读取这两份文档；局部修改时读取两份文档中对应的部分。

## 1. 文案组成与顺序

按下表顺序填写`文案.md`。有条件的部分按实际情况写，不为凑齐栏目增加内容。

| 组成 | 让读者明白什么 | 何时填写 |
| --- | --- | --- |
| 标题 | 这是哪个数据库、什么主题 | 必填 |
| 摘要导读 | 得到哪些结果，结果之间是什么关系 | 必填；关系树按需要添加 |
| 原始问卷 | 调查实际问了什么，怎样提问 | 有已核实的原题或题意概括时填写 |
| Criteria | 每个变量的含义、取值方法及必要限制 | 每个最终变量都填 |
| 小book提示 | 多组结果或整个主题使用时要注意什么 | 有这类提醒时填写；没有则使用约定的省略句 |
| 参考资料说明 | 定义方法有哪些依据 | 有实际使用的方法资料时填写；没有则省略该节 |

生成后的笔记会把小book移到原始问卷之后，并自动加入数据库目录入口、图表和附件；这些不用手写进文案。

通用写法：用读者能理解的话说明具体事实，名称已经清楚就不再释义。同一信息放在最合适的位置；再次提及时应有不同用途。全篇名称的对象、方向、时间和单位保持一致。初稿依据本次已确认事实，不照抄旧稿；来源不明、方案未定时先解决事实问题，不在写作时自行增加口径。

通用格式：使用Markdown，不手写HTML或CSS。变量名和代码用反引号，数字与量词间留一个半角空格，百分号紧贴数字。

## 2. 标题

**目的**：让读者识别数据库和主题。

**内容要求**：主题名称准确覆盖实际定义，不扩大范围，也不堆列所有变量。中文与英文含义一致。

**格式要求**：一级标题，使用“数据库 — 中文主题（英文主题）”，不加主题序号。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#2-标题)。

## 3. 摘要：最终得到什么

**目的**：读完开场，知道最后得到什么，以及这些结果怎样联系。

**内容要求**：

1. 先介绍最终结果。有综合结果时，先写它及由它划分的类别，再写分项和辅助结果；没有综合结果时，按实际测量内容介绍。多个结果说明总数，不能用“等”代替遗漏项。
2. 再交代关系：如何相加、平均或加权；分数高低表示什么；哪些条件对应哪一类；结果是否独立或可能重叠。只写本主题实际存在的关系。
3. 名称已说清含义就不再解释；必要时补对象、时间或单位。可以按实际内容成组介绍，不用“若干分项”或代码范围替代测量内容。

原题怎样赋值、换算、反向计分和完整缺项处理，放Criteria。摘要可以保留帮助理解的简短条件，如“仅限全部题目均有效”；不用把算法展开。检索过程、逐期来源代码和目录路径不放这里。

**格式要求**：二级标题为“摘要导读”。结果名称用中文双引号，概念用`**加粗**`标记；数量只加粗数字，不加粗量词。同一段或连续信息块内同一概念只强调首次出现，共享的结果维度也要明确标记。

**关系树，可选**：多层结果关系可在摘要文字后画树；只有一层关系时不用画。节点写结果名称，连线写组成或分类关系，可带范围、阈值和简短必要条件，不画原题清洗流程。使用无语言或text代码围栏，保留树线及前导空格；现有渲染器负责显示样式。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#3-摘要最终得到什么)。

## 4. 原始问卷：调查实际问了什么

**目的**：让读者看到定义所依据的实际问题和提问程序。

**内容要求**：

1. 先按内容分组。题意、对象、回顾期、选项含义和提问路径相同的时期合并展示；实际变化的题目另列适用时期。只有题号或编码写法不同，集中说明对应关系，不重复整组题目。导出值相同不能代替问卷核对。
2. 每组先写问卷设计：问谁、问什么、怎样提问、用于哪些结果。测验或访员说明只保留影响题义或取值的部分；概括不逐题复述原题。
3. 再展示题号、完整中文题干、选项、单位及必要进入条件和跳转。外文题目译成完整中文，不以英文全文加中文概括代替。仅能确认题意、无法取得完整原题时，写出已核实的题意概括，并说明无法提供完整题文的原因，不伪造原题。

按人物或项目反复提问时，交代实际对象和每次记录的信息，不由变量后缀猜人数或顺序。共同选项可集中说明，但不能省掉题干和实际差异。不同来源的调查事实与数据记录方式分开说，不从缺少变量推定调查未问；本项目的赋值方法放Criteria。

**格式要求**：

- 二级标题“原始问卷”，三级标题写适用时期；每期先用四级标题“问卷设计”或“问卷设计变化”写设计说明，再用四级标题写题号。标题由文案提供，生成器按原文显示一次。连续时期可写`Wave 1–3`，不连续时期明确分开，不能暗含未核实年份。
- 仅能核实题意、无法取得完整原题时，在本期问卷设计中写“题意概括：”和“未取得完整原题的原因：”，分别给出已核实内容及实际原因；不为展示概括编造题号或选项。
- 原题题干不加引号；设计说明中概括的问题用中文双引号。必要访员说明放本组设计说明。
- 单题选项用短横线，保留原始编码和标签。编码写法分期变化时，可用`原问卷选项编码（适用时期）：编码=标签；编码=标签。`集中说明，题块只列共同标签；解码后的数据值另说清楚。
- 多题共同选项放在本期设计说明中，写成`共同选项（Q1、Q2）：1=是；2=否。`；多题共同跳转写成`共同跳题（Q1、Q2）：完整触发条件 → 目标题号。`。括号逐项列出适用题号，条件不能简写掉参与判断的题；句号结束该条。共同选项不再逐题重复，单题特有选项和跳转仍放本题。
- 有进入条件才写“适用对象：”，给出判定题及回答，多题共同决定时完整说明。只有代码不能说明对象时，补题义。
- 条件跳转紧跟对应选项，写`→ 跳至 题号`；不再返回本主题时写`→ 结束该主题`。普通顺序作答不补“继续下一题”。不能归入单项的真实流程才写“跳题说明：”。

## 5. Criteria：每个变量怎样得到

**目的**：让读者理解每个变量，并能据此判断一条记录该取什么值。

**内容要求**：每个最终变量填写一组，名称与方案一致；先写组成变量，再写综合变量。多个变量共用的定义条件或处理写在`## Criteria`下、首个变量之前，明确适用变量，成品在定义表前显示一次；没有则直接写各变量。

| 栏目 | 内容 |
| --- | --- |
| 定义 | 用一句话说明变量表示什么，带上必要的对象、回顾期或单位 |
| 定义逻辑 | 说明所用信息、如何得到取值及必要特殊处理，具体写法见下方 |
| 分类 | 列出最终编码与含义；数值变量说明类型和单位。使用方案确定的类别，不拿原问卷编号替代结果编码；实际分布留在QA |
| 注意点 | 写使用时必要的换算依据、时期差异或比较限制，不重复计算步骤；没有就省略 |

定义逻辑按实际判定或计算顺序组织，只写涉及的内容：

1. **所用信息**：哪些回答、测量值或已定义变量；有不同对象、时期或来源时，交代适用范围和选用顺序。共同条件集中说明。
2. **如何取值**：回答与编码的对应、分组条件或计算方法。原始数值直接作为结果时，说明二者对应即可；换算、合成时写清运算、单位和权重。使用已定义变量时接着写，不重复此前生成过程。
3. **特殊处理**：补零、回填、缺项后是否计算或折算，写明条件和处理。前置跳题补值须说明适用时期、哪些前置回答共同触发、哪些结果补为什么值；存在容易混淆但不能补值的路径时一并区分。普通未回答且没有另作处理，不专门补写“保留缺失”。

所有条件都来自已确定方案，原始回答用真实选项。调查提问流程放问卷；使用限制放注意点；防报错的程序细节留在代码。一句能说清就写一句，不为完整形式增加背景或步骤。

**格式要求**：二级标题“Criteria”；三级标题用实际变量名；四级标题依次为“定义”“定义逻辑”“分类”“注意点”。定义逻辑有多项时用①②③；分类用短横线，取值、编码及类别用方括号。没有注意点时删除整个栏目。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#5-criteria每个变量怎样得到)。

## 6. 小book：跨变量或整个主题的使用限制

**目的**：提醒读者在共同使用多组结果或整个主题时，哪些实际差异会影响解释、比较或汇总。

**内容要求**：只影响一个变量的提醒放它的注意点；一组变量共有的计算或缺失条件放Criteria。确有跨组或主题共同使用问题，且不能在上述位置讲清，才写小book。每点说明“实际有什么情况，会影响怎样使用”；本次确实作了处理才补处理结果。同一提醒选一个主要位置，不汇总重复内容，不搬入探索过程或QA计数。

**格式要求**：二级标题“小book提示”。多点用`1. `、`2. `编号，每点一段；只有一点不必编号。不规定提示数量。没有这类提示时，正文写固定句“本主题没有需要单独提示的主题级边界”，生成器会省略卡片。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#6-小book跨变量或整个主题的使用限制)。

## 7. 参考资料说明

**目的**：说明采用的方法或解释限制有什么依据，哪些是本项目另作的选择。

**内容要求**：没有实际使用的方法资料时省略本节，不为填满栏目补文献。只列实际支持公式、计分、分类、阈值或解释限制的已核实材料。每条说明材料讲了什么、支持本主题哪部分；必要时说明它没有规定、由本项目决定的处理。普通应用文章留在探索记录；已在问卷展示的调查事实不再重复列作方法文献。

**格式要求**：二级标题“参考资料说明”。使用`> 1. `逐条独占一行，条目之间不空行。材料名链接到已核实地址；没有链接时给版本和页码，不编造地址。

**模板与实例**：[查看本部分](../../../templates/reader-copy.md#7-参考资料说明)。

## 写作所需的程序操作

问卷证据登记、变更范围记录、机械检查和首稿保存，按[文案程序操作](../scoped-tasks.md#copy-operations)执行；这些不进入正文，不构成固定内容自查。正式生成与显示样式由[生成环节](05-generate.md)负责。
