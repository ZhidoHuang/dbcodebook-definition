# NHIS 数据集接口

## 选择入口

1. 使用 `database=nhis`。同时指定 `dataset_id`：`nhis_pre1997`、`nhis_1997_2018` 或 `nhis_2019_plus`。
2. 使用 `/home/nhis/{dataset_id}/`。`/home/nhis/` 只用于选择数据集。
3. 核对所选数据集的目录、来源身份和时期。三个数据集不能因同属 NHIS 而混用字典或下载包。

当前适配常规年度调查的唯一个人文件。专题、随访、重复事件和插补记录不由本适配自动支持。出现这些来源时，说明实际文件结构与所缺能力，暂停依赖操作。
当前来源证据由开发者版的只读字典入口取得；纯网页来源读取尚未接入。后续选择、下载、生成和发布使用公共入口。

## 来源身份

- 完整身份包含数据集、字典指纹、`Variable_id`、`Variable`、`File` 及逐期来源映射。同名同文件仍可能有多个版本，不能取检索结果第一行。
- 开发者版详情使用 `Variable_id`、当前 `dictionary_sha256` 和明确的字典时期。目录路径取 `variable_section_sources`，不把显示列中用“or”连接的目录当作一条路径。
- 来源记录增加顶层 `dataset_id`。在 `nhis_selection` 保存 `dictionary_sha256` 和 `inputs`；每项包含 `variable_id`、`variable`、`file`、`alias`、`periods`、`source_mappings`。
- `source_mappings` 保留字典返回的调查期间、来源文件标识、原变量名、合并文件、合并变量名、编码版本及记录单位。`source_groups` 仍按公共格式记录完整来源与别名。
- 固定选择入口使用 `Variable (File) [Variable_id]=别名` 批量选择。网站按ID核实完整来源并设置别名；不将ID省略后按同名匹配。

## 时期与连接

- 年度数据是重复横断面，不能把不同年度的住户编号当作同一人。
- 保留网站生成的字符型 `ID`、`Wave_id`、`Survey_year`。不要从住户号重建个人身份。
- 早期字典的1963至1967列对应实际导出的1963FY至1967FY。1968FY和1968CY分别保留，不合成一个1968期。
- 标准调查与另行发布的版本分别核实。不能把1992年标准版与不含西语裔增补版直接叠加。
- 不同文件是否可连接，依据实际记录单位、连接说明和下载后身份检查判断，不依据变量名推断。

## 下载与生成

1. 选择、登录和下载命令同时传 `--database nhis --dataset-id <所选数据集>`。
2. 保留本次网站下载的 `raw_data.csv`、`raw_codebook.csv` 和连接说明。默认身份列不重复加入业务来源。
3. 下载检查同时核对原始包、准确选择清单、别名、默认键、时期及个人键唯一性。三列代码本本身不能证明版本身份。
4. 正式 R 将默认键按字符读取。两份最终表均保留默认身份列，每人每期一行；各期受访者不作为纵向面板连接。
5. 生成器使用 `database="NHIS"`、明确的 `dataset_id`、实际 `cycle_order` 和以来源别名为名的 `nhis_source_ids`。来源ID用于提取入口定位版本；生成器只在显示副本中投影时期，不改原始文件。
6. 周期图展示该数据集完整周期；变量没有数据的周期保留空格。FY/CY标签不改成普通年度或Wave编号。

网站发布使用来源记录的dataset_id选择对应具体分类：`NHIS 1996年及以前`、`NHIS 1997—2018`或`NHIS 2019年及以后`。不按笼统NHIS分类发布，不从文章标题猜数据集。两层数据库菜单先打开NHIS系列，再选择对应数据集；普通单层菜单仍沿用原入口。

研究、定义、问卷、独立 R 复核和网站同步继续执行公共规则。接口检查通过不代表三个数据集的全部主题均已验收。
