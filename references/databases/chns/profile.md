# CHNS 接口边界

网站入口为 `/home/chns/`。当前候选校验只覆盖个人—调查年唯一文件及跨期静态个人文件；家庭、社区、关系、重复明细的分析单位不同，不能当个人文件自动拼接。

- 网站时期：1989、1991、1993、1997、2000、2004、2006、2009、2011、2015。以实际来源覆盖为准，不补不存在的年份。
- 普通个人文件按平台 `ID` 合并导出为 `raw_data.csv`，个人与时期字段为 `IDind`、`WAVE`。保留字符串身份，不解析平台ID来补字段。
- 实际CSV可能将整数年份显示为 `1989.0`；合同与渲染工作副本可按整数等值年份比较，仅接受四位年份及全零小数部分，不接受分数、科学计数或不支持年份。个人键如 `211101001001.0` 继续保留原字符串，静态连接按实际个人键对应，不删 `.0` 或重写raw。
- 静态个人文件按原文件名单独导出，如 `raw_data_mast_pub_12.csv`，键为 `IDind`，不是个人—年记录。只有已明确连接关系时才在工作对象中按个人键多对一连接，原始文件保持不变。
- 同一 `ID` 的辅助身份字段跨来源冲突时，网站可能保留 `hhid (来源文件)` 等列；不能丢掉后缀后任选一列。个人键或时期本身冲突时先解决来源关系。
- 字典保存 `Variable (File)`、`newname` 与 `File type`。`uniqID` 和 `personID` 分别对应上述两种文件；完整来源身份与下载别名不可混用。

公开R按字符读取主文件的 `ID`、`IDind`，静态文件按字符读取 `IDind`；可按字符保留经字典核实的其它自动身份列，不改变业务列类型。静态表在公开计算区显式读取，并按 `IDind` 执行 `left_join(..., relationship="many-to-one")`；未匹配静态信息保留缺失，不补造。两表同名业务列或重复静态键必须先解决。工作对象包含接入的静态来源，原始CSV保持不变。mapping仍从同一 `raw_codebook.csv` 的 `newname` 对应完整 `Variable (File)`，不要求所有别名出现在主文件。

生成接口显式指定 `database="CHNS"` 和实际来源支持的 `cycle_order`。生成器仅在本地渲染副本从 `WAVE` 建立年份列，校验三份个人—年对象的身份和时期，不负责接入或补造静态业务列。完整检查按字典 `File type` 定位每个别名，所有静态CSV也须列入正式成果检查范围。

本轮已观察普通网页预览及只读导出源码；fixture验证包结构、分文件来源、十期身份、静态读取及工作对象多对一连接和完整检查器的分文件分派。已只读检查一个真实下载包的整数年份文本、个人—年唯一键、静态键及连接覆盖，但静态显式别名与选择回执不一致，该包未通过完整合同、未正式安装。尚未验证全量静态信息连接后的完整定义或完整笔记生成。具体主题出现数值字段被发布为标签等异常时，单独核实，不改原始文件来掩盖。
