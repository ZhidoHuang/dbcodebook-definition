# CHARLS 数据库 profile

版本日期：2026-08-14

适用范围：记录 CHARLS 的稳定入口、身份结构和数据库级核验要求。本文件不是标准流程、主题定义、主题经验或历史复盘。

正式源：本文件是 Skill 仓库中的 CHARLS profile；机器路径和网站域名由外部配置提供。

## 1. 稳定入口与身份

- dbCodeBook 页面：外部配置中的 `website.base_url + website.database_paths.charls`。
- 正式主题目录：外部配置中的 `paths.formal_root/CHARLS/<编号_主题>`。
- 过程证据目录：外部配置中的 `paths.process_root/CHARLS/<编号_主题>`。
- 主题编号、状态、最终变量、transaction 和唯一日志，以 `主题索引.md` 与 `定义验收台账.md` 为准。
- 已完成主题的口径以正式 R、raw、codebook、definition、笔记和机器闭环证据为准；不得从本 profile 推断具体变量。

## 2. 数据库级核验

- 候选从真实 dbCodeBook 目录和普通检索发现，官方题目详情优先于 Easy label。
- 相同变量名或近似 Easy label 必须逐年核对题干、取值、目录、文件身份和适用对象；不得只凭变量名跨期拼接。
- 同一 raw 后缀在不同年份可能对应不同概念；跨期定义按题义身份重建，不按后缀机械对齐。
- `997`、`998`、`999` 等高位编码可能表示不知道、拒答、不适用、未问、其它特殊选项，也可能在个别题目中是合法值。连续变量、金额、时长、次数、日期、总分和换算变量必须结合官方题目、raw_codebook 和实际分布逐项判定，不能使用全库统一字典。
- CHARLS 同时包含个人、家庭、家庭成员明细和社区等不同分析单位。使用家庭或社区来源时，必须说明下载粒度、正式输出粒度、匹配键和数值是否会在个人行重复；不得默认所有来源都是个人-波次记录。
- 预载、上一波次信息、整理变量、辅助跳题来源和当期直接回答是不同证据身份。只有正式逻辑确实需要时才组合，并在用户材料中解释会影响理解的差异。

## 3. 主题事实边界

- raw 选择、变量名、公式、阈值、编码、缺失、跳题补 0、跨期比较和输出结构，均由本轮真实探索、官方材料、实际 raw、正式 R 和用户裁决确定。
- `探索记录.md` 用大白话同步保存真实发现与判断过程；`definition_search_record.json` 保存同一步骤的结构化来源身份和候选取舍；recover 报告、核对报告和 machine closure 保存机器证据。
- profile 只沉淀跨主题稳定事实。单主题变量名、题号、金额异常、年份特殊情况和措辞不回填到本文件。
- 发现新的数据库级逻辑漏洞时立即汇报；只有用户确认具有通用性后，才更新本 profile。
