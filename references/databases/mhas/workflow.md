# MHAS 执行差异

按公共八步流程执行，身份和文件范围见 [profile](profile.md)。

1. 来源探索使用原始库；逐期核实本人和代理问卷、前置筛查及缺失编码。
2. 下载仍由网站固定入口完成。接收器验证Core文件名、来源字典、所选字段、默认身份列及每人每期唯一性。
3. 正式R读取原名文件，保留身份为字符；最终输出每人每期一行。缺失值不作为分类。
4. 公共生成器显式传 `database="MHAS"` 及已核实的 `cycle_order`；不得从非缺失行反推时期。
5. 完整检查使用 `--db mhas`，所需文件清单包含原名Core CSV。

ADL已完成七期真实下载、九变量生成及独立逐行复算。网站发布状态及具体范围以主题执行报告和[验收矩阵](../../../tests/acceptance-matrix.md)为准；不据此推定其他模块或主题通过。
