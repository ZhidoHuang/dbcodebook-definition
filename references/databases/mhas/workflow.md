# MHAS 执行差异

按公共八步流程执行，身份和文件范围见 [profile](profile.md)。

1. 来源探索使用原始库；逐期核实本人和代理问卷、前置筛查及缺失编码。
2. 下载仍由网站固定入口完成。接收器逐文件验证profile所列文件名、来源字典、所选字段、默认身份列及每人每期唯一性。
3. 正式R逐个读取原名文件，保留身份为字符；最终输出每人每期一行。多文件按已定方案整理，不把文件堆叠当作已完成同人连接。缺失值不作为分类。
4. 公共生成器显式传 `database="MHAS"` 及已核实的 `cycle_order`；不得从非缺失行反推时期。
5. 完整检查使用 `--db mhas`，所需文件清单包含本次全部原名CSV。

## 新版来源身份

新版字典使用 `Variable_id＋时期` 定位来源，字典 SHA256 标识版本。原名相同不表示同一个来源。

- 采用新版时，在来源记录的 `mhas_selection` 保存字典 SHA256、逐项 Variable_id、文件、可用时期和实际列名。原始变量名仍保存在 `source_identities`。
- 当前网站按实际原始列与文件选择、导出。来源记录设置 `mhas_selection.mode="raw_columns"`，固定入口逐列输入 `原始列 (文件)=别名`；不输入整个系列来代替已定列清单。
- 固定入口核对网站返回的原始列、文件及全部可用时期，再核对实际标签和别名。来源ID及字典版本仍由本地证据核实，不把网页未返回的字段记为网页已验证。
- 下载别名沿用公共来源命名规则。网站直接使用填写的别名，不追加原变量名或时期。
- 同一原始列在同一文件中只保留一个下载别名。该列跨期题义不同时，可以保留原列名作为共同别名；业务方案和R分别说明各时期怎样采用，不把不同题义合并为一个结果。
- 原始列导出其全部可用时期。业务采用时期单独保留在已定方案中，R仅在这些时期使用该来源；列内有其他时期的值，不表示可以扩大定义。不得把下载范围与业务范围当作同一条件。
- 历史按ID及时期选择的动作仅解释其原有记录；当前网站任务不沿用旧选择动作。
- 旧包沿用其原有身份和证据，不将新版身份反写进旧凭据。

当前实际列选择、下载及生成接口仅覆盖 [profile](profile.md) 所列个人文件与时期；其他文件层级及跨模块桥接仍需单独适配。


### Core/NOK/Mex-Cog 分区接口

采用的各原始问卷文件分别读取后显式附加对应 `source_module`，不得按相同 ID 连接。按已确认业务时期筛选分析行，原始文件不删行。来源记录的 `mhas_analysis_scope` 同值传入 `render_definition_bundle(..., mhas_analysis_scope=...)`；最终 Python 检查按模块、时期、实际默认身份列核对全部应保留行。结果采用时期按已确认方案声明，其他物理时期的附带原始行不扩展定义范围。最终结果范围和包文件时期是两种契约。

Mex-Cog Cognitive Assessment 与 Informant Interview 保留独立文件和结果归属。2016 小写身份组件与 2021 大写组件按 [profile](profile.md) 逐期核对，不将知情人当作结果测量对象。文件存在两个时期不证明 COVID 在两个时期都提问；问卷、可用列和业务时期分别取证。

启用 `mhas_analysis_scope` 时，来源记录和独立 R 调用均显式声明 `identity_keys = c("source_module", "ID", "Wave_id")`（JSON 使用同序数组）；`analysis_unit` 保持 `person_period`，含义为来源模块内每人每期。归属结果的并集必须与 `approved_analysis_vars` 一致。
