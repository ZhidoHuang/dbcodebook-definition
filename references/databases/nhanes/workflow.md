# NHANES 执行差异

沿用公共阶段规则，不新增独立执行流程。

1. 从[数据库差异](profile.md)确认来源类型及身份列。开发者入口使用已绑定当前网站的本地字典。
2. 批量选择写成 `RIAGENDR (常规(唯一SEQN))=A_sex`。固定网页入口核对来源类型、变量和别名。
3. 下载恢复入口使用 `--database nhanes`，核对默认身份列、来源字典及个人—周期唯一性。
4. 公共生成器使用 `database="NHANES"`，显式传入已核实的 `cycle_order`。仅在渲染副本中把 `YEAR` 投影为 `year`；交付表保留原身份列。
5. 按公共结果检查与网站同步规则交付。旧文章更新保留原文章编号。

已实际验证普通人口学42个来源、12个发布周期的下载与生成。104行样本调用公共生成器后，全量128809行生成成功；30项结果与既有网站算法逐值相同，五项封顶人数另按原始值独立复算通过。

`YEAR` 保留完整范围，如 `2017-2018` 与 `2017-2020`，不能转换为单个年份或合并两个重叠周期。摘要及图表均使用原周期标签。

完整成果检查与发布以主题执行报告为准；不据此宣称其他主题、重复记录来源、受限数据或其他设备的网页来源探索已经验证。
