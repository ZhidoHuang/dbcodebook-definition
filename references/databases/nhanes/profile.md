# NHANES 数据库差异

- 网站入口为 `/home/`，不与 NHANES III、Harmonized 或 KNHANES 混用。
- 来源身份为 `Variable` 与 `数据源类型`。选择接口支持“常规(唯一SEQN)”、`PAQIAF` 活动明细和 `RXQ_RX` 处方明细。同名变量不能跨数据源类型替换。
- 普通来源导出 `raw_data.csv` 和 `raw_codebook.csv`。默认列 `SEQN`、`YEAR` 不作为业务变量重复选择。
- 在公开 R 中按字符读取并保留 `SEQN`、`YEAR`。最终长表按这两列检查唯一性；同一 SEQN 在不同周期不自动合并。
- `YEAR` 保留原周期字符串，例如 `2017-2018`。重叠周期仍分别保留；是否选用或排除某个周期由已确定的主题方案决定。
- 字典用 `Variable`、`File type`、`newname` 对应原变量、文件层级及下载别名。普通来源的 `File type` 为 `uniqID`。

| 来源类型 | 数据文件 | 默认列与记录单位 |
| --- | --- | --- |
| 常规(唯一SEQN) | `raw_data.csv` | `SEQN`、`YEAR`；每人每期唯一 |
| PAQIAF | `raw_data_PAQIAF.csv` | `RowIndex`、`DOC_FILE`、`SEQN`，源中存在时另有 `YEAR`；每条报告活动一行 |
| RXQ_RX | `raw_data_RXQ_RX.csv` | 同上；每条处方访谈记录一行，同人同周期可有多行 |

- 明细的字典 `Variable` 保留 `变量 (数据源类型)`，`File type` 为 `reID`。默认列不重复选择。
- `DOC_FILE` 保留来源文件；`RowIndex` 仅标识本次导出中的原行，不能作为跨文件连接键。
- 明细未提供 `YEAR` 时，在工作对象中按已核实的发布文件映射周期；不改原始CSV，不从 `SEQN` 猜周期。`PAQIAF(.xpt)`、`PAQIAF_B/C/D(.xpt)`分别对应1999–2000、2001–2002、2003–2004、2005–2006；`RXQ_RX(.xpt)`、`RXQ_RX_B`至`RXQ_RX_J(.xpt)`按对应发布周期映射，`P_RXQ_RX(.xpt)`对应2017–2020。程序集中保存同一映射，未知文件名或 `YEAR` 与已核实文件周期冲突时停止核对。
- 明细原行全部保留。同人多行、相同活动或相同药物记录不能据此自动去重。
- 先按已确认方案将明细汇总至 `SEQN`、`YEAR` 唯一，再连接个人—周期主表。核对汇总键、未匹配记录及连接前后主表行数。
- 明细无记录不等于否定回答。按本主题已核实的前置题和缺失方案判断，不默认补0。
- 药物分类专用页面 `/home/medicine/` 与 `RXQ_RX` 原始明细不是同一来源。专用导出须另核实匹配项、匹配列、记录单位与周期，不能当作普通来源直接连接。
- 受限数据、无个人编号的药物字典及其余来源类型未接入。
