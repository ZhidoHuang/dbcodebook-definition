# 数据库参考材料

按数据库进入材料索引；无需扫描原设备的 Database 目录。材料入库与完整定义流程适配是两回事。

| 数据库 | 入口 | 流程支持 |
| --- | --- | --- |
| CHARLS | [现有材料](charls/) | 已有专门流程；验证范围按具体主题和时期记录 |
| ELSA | [现有索引](elsa/材料索引.md) | 已有专门流程；验证范围按具体主题和时期记录 |
| HRS | [材料索引](hrs/材料索引.md) · [检索目录](hrs/材料目录.html) | 已有Full HRS流程；真实下载及完整流程仍受验收边界限制 |
| SHARE | [材料索引](share/材料索引.md) · [检索目录](share/材料目录.html) | 普通Wave1–9人口学完整流程已验证；其他记录层级未验证，见[范围与限制](../databases/share/workflow.md) |
| KLOSA | [材料索引](klosa/材料索引.md) · [检索目录](klosa/材料目录.html) | 已有显式语言的个人文件候选接口；[范围与限制](../databases/klosa/workflow.md)，完整生产尚未验收 |

| CHNS | [材料索引](chns/材料索引.md) · [检索目录](chns/材料目录.html) | 十期人口学已完成真实下载、生成、独立复算和发布；[已验证范围与接口边界](../databases/chns/profile.md) |

各数据库材料统一位于本目录对应小写数据库名下，按各库索引和清单定位原始材料。manifest.json 校验全部文件的内容哈希，副本关系见各库清单。

流程入口见[数据库路由](../database-routing.json)。哪些操作、主题和时期已经验证，以及仍未验证的部分，统一查[验收记录](../../tests/acceptance-matrix.md)中的对应数据库和任务；历史通过不代表当前版本或全库通过。本索引不另维护一份验收结论。
