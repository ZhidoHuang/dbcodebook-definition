HRS 2000 Imputation Release (Version 2.0)
December 18, 2002 

The HRS 2000 Imputation Data Release (Version 2.0) is now available. Based on the 
2000 HRS final core data (version 1.0, September 2002), this release supersedes 
the previous release (Version 1.0, October 2001) of this data. 

Compared to the previous version, this release includes for the first time the 
imputations for Sections DFC, DH, and DTC. It used a slightly modified imputation 
program that is more consistent with one used for the imputations in other 
HRS/AHEAD waves.

Please note that although the most extreme outliers were excluded from the 
imputation process used to fill missing data, they remain in the reported data. 
Users may wish to review distributions and consider the use of robust statistical 
procedures to minimize the impact of any outliers on their analyses. 

If you find any problems with the data, please report them to us via the Help Desk, 
or by sending e-mail directly to hrsquest@isr.umich.edu.
