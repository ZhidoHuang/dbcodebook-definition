collection period. They are provided for the convenience of users who wish to 
begin analyzing data prior to a final release being available. Early release

-------
SUMMARY
-------

This file contains sampling weights for household and respondent level
analyses. Both of these weights have been post-stratified so as to reproduce
CPS distributions with respect to birth year, gender, race and ethnicity.
Details can be found in the file wghtdoc.pdf, which is part of the Tracker
Version 2 release contained in the file track020.zip. The household level
weights should be merged to analysis files on the basis of HHID, and to
respondent level analysis files using HHID and PN. The variables included in
the file are

   HHID : the six digit string household identifier
   PN : the three digit string respondent identifier
   GWGTHH : the post-stratified sampling weight for household level analyses
   GWGTR : the post-stratified sampling weight for respondent level analyses

-----
SETUP
-----

The file "h2000wt.zip" contains all the HRS 2000 early release weights files.

To set up the HRS 2000 early release weights files on your own computer,
please complete the following steps: 

1. Create the directory where you wish to decompress the files. We recommend
   you use "C:\h2000wt", but this is not required. If you choose another
   directory, you will need to change the directory paths in your SAS, SPSS,
   or Stata statements.

2. Place the file "h2000wt.zip" in the directory from Step 1.

3. In the directory from Step 1, create the following subdirectories:

     \CODEBOOK
     \DATA
     \DESC
     \SAS
     \SPSS
     \STATA

4. Within the compressed file h2000wt.zip are 8 files, all of which are
   in ASCII text format. The resultant files are named, formatted, and used
   similarly to files in most HRS final releases. Use your favorite ZIP
   compression software (for example, PKUnzip or WinZip) to decompress file
   "h2000wt.zip" into the appropriate directory. (For example, decompress file
   "h00_wgt.da" into subdirectory "/DATA".)
