Data Alert:
1995 AHEAD Helper Imputation File Replaced
02/27/2003

The 1995 AHEAD Helper imputation file has been re-issued. The new file contains two identification variables
not included before: PN (Person Number) and DHLPTYPE (1995 Helper Type). Users who downloaded the file before
02/27/2003 should use the updated 1995 AHEAD Helper imputation file to avoid problems when merging with the
1995 AHEAD Core Helper file.
