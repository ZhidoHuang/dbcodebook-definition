HRS 1998 Imputation Release (Version 3.0)
December 18, 2002

The HRS 1998 Imputation Data Release (Version 3.0) is now available. This 
release supersedes the previous release (Version 2.0, April 2002) of this 
data. It corrects modest errors in the annualized values of some variables 
in Section J due to ignoring the spread of data collection across two 
calendar years. This has a slight impact on the constructed variable "total 
household income in the last calendar year" (FHHINC). Anyone using the 
household income variable should replace it with this new version.

Please note that although the most extreme outliers were excluded from the 
imputation process used to fill missing data, they remain in the reported 
data. Users may wish to review distributions and consider the use of robust 
statistical procedures to minimize the impact of any outliers on their analyses.

If you find any problems with the data, please report them to us via the Help 
Desk, or by sending e-mail directly to hrsquest@isr.umich.edu.
