The Definition of the 'S' -- Summary Bracket -- Variable: A summary bracket 
variable summarizes the bracket information embedded in a set of individual 
bracket variables. Each bracket question, if asked, yields a single-digit 
response (1=less than, 3=about, 5=less than, 8=do not know, 9=refused), which we 
name v1 through v4 for four bracket questions, v1 - v5 for five brackets, etc. 
Whatever the actual sequence of bracket questions, v1 refers to the lowest amount 
and v4 (0r v5) refers to the largest. The summary bracket variable is calculated 
simply as v1 + 10*v2 + 100*v3 + 1000*v4 +10000*v5... Missing values on any 
individual bracket variables are converted to zero (0) before the operation. 
In addition, there are three special codes reserved for an 'S' variable: '-2' 
indicating that the missing value on the 'X' variable was legitimate (no imputation 
was necessary); '-1' indicating that the original value of the 'X' variable was 
not missing; and '0' indicating that the 'X' variable was imputed without any 
bracket information. For more information about the imputations, please check the 
documation file, 'IMPUTE: A SAS Application System for Missing Value Imputations' 
at http://hrsonline.isr.umich.edu/docs/userg/dr-007.pdf. 

Cross-Variable Inconsistenies in the Asset Distribution Variables: Due to the 
structure of the data, there might be some inconsistencies across the asset 
distribution variables in Section NR. These variables include the total value of 
a respondent's asset (Q2507X), and the respondent's asset distribution (amount 
and percentage) to spouse (Q2426Z and Q2427X), children (Q2437Z and Q2438X), 
charities (Q2459Z and Q2460X), siblings (Q2469Z and Q2470X), relatives (Q2479Z 
and Q2480X), friends (Q2489Z and Q2490X), and others (Q2499Z and Q2500X). 
The sum of the all the distribution components might not be same as the single, 
total asset value varible (Q2507X). Please note that the inconsistencies arise 
not just because of our imputation strategy, which treats each of the 14 asset 
distribution components individually, but also in the original data reports. 
Users are adivsed that they perform the consistecy check among those variables, 
and fix the problem appropriately before using the data.
