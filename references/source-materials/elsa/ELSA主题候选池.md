# ELSA 主题候选池

版本日期：2026-08-09

本文件只保存可供后续探索的主题方向，不是主题索引、开题顺序、编号计划或正式定义依据。

- ELSA 主题按该数据库实际开题顺序独立编号，不与 CHARLS 或本表顺序对应。
- 开题时必须重新完成 dbCodeBook 目录探索、普通检索、Wave 来源核对、研究口径判断和命名查重。
- 本表中的“定义方向”和“关注点”只用于提出问题，不能据此选择 raw、确定公式或创建正式目录。

| 主题方向 | 可探索内容 | 开题时重点核对 |
| --- | --- | --- |
| 吸烟 | 曾经吸烟、当前吸烟、吸烟状态 | Core 与 IFS 来源身份、当前题与历史信息的关系 |
| 饮酒 | 过去一年饮酒频率、当前是否饮酒 | 频率分档、不同 Wave 的题目覆盖 |
| 身体活动 | 三种强度频率、活动水平 | Core 原题与官方派生指标的覆盖差异 |
| 睡眠 | 睡眠时长、失眠症状、睡眠质量 | 各维度是否同步覆盖全部 Wave |
| ADL | 六项困难、任一困难、困难数 | IFS 派生来源与 Core 来源衔接 |
| IADL | 分项困难、任一困难、困难数 | 早期与后期项目数量变化 |
| 记忆 | 即时回忆、延迟回忆、记忆总分 | 词表、回忆轮次与计分来源变化 |
| 其它认知能力 | 定向力、语言流畅性、计算能力 | 各任务的 Wave 覆盖和可比边界 |
| 认知综合指标 | 记忆、执行或精神状态及总认知 | 组成变量和合成证据是否充分 |
| 抑郁症状 | CES-D 单项、总分、筛查指标 | ELSA 版本及反向题处理 |
| 孤独感 | 单项或 UCLA loneliness 指标 | 单项与量表不能混为同一变量 |
| 生活质量 | CASP 单项、分量表或总分 | CASP-19 与简化版本的衔接 |
| 生活满意度 | 原始顺序分类或连续评分 | 题目量尺变化与解释边界 |
| 社会参与 | 组织、社交、志愿和文化活动 | 活动集合随 Wave 变化 |
| 社会隔离 | 婚姻、联系、参与等维度及总分 | 文献口径与当期信息完整性 |
| 慢性病与共病 | 分病种诊断、任一慢病、共病数 | 新诊断、历史诊断和 feed-forward |
| BMI 与身体测量 | 身高、体重、BMI、腰围 | 自报与 Nurse 实测来源分开处理 |
| 握力与身体功能 | 握力、步速、起立或平衡任务 | Nurse Wave 覆盖与测量有效性 |
| 跌倒与行动能力 | 跌倒、行动困难、行动项目计数 | 回顾期和题组变化 |
| 疼痛 | 是否疼痛、部位、严重程度 | 不同疼痛题不能机械合并 |
| 视力与听力 | 自评视力、自评听力、功能困难 | 辅具使用条件与题义差异 |
| 医疗服务利用 | GP、门诊、住院及次数 | 回顾期和英国医疗服务语境 |
| 照护需求与获得 | 需要帮助、获得帮助、未满足需求 | 与 ADL/IADL 的关系及适用对象 |
| 非正式照护 | 是否提供照护、对象、频率或时长 | 家内与家外照护分开 |
| 照看孙辈 | 是否照看、频率或时长 | 适用对象和家庭结构变化 |
| 就业与退休 | 就业状态、退休状态、工作时长 | 受访者状态与配偶状态分开 |
| 收入与财富 | 收入、净财富及主要组成 | 官方派生、插补值和价格口径 |
