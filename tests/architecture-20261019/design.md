# Agent 执行路径迁移设计

本记录用于维护和验收，不是生产任务必读文件。基线为 2026-10-19 本轮修改前的本地工作区，包含已有未提交修改；逐条原文、位置和去向见 migration.jsonl。不得以 HEAD 代替该基线。

## 范围与批次

用户要求：先补齐读取路径、覆盖边界、逐条追踪、验收对应及真实案例比较，再分批修改。第一轮报告中的新增 writing/operations/rendering 文件目录不直接实施。

1. 设计与基线：登记规则和模板原文、程序哈希，核对三类实际案例的方案与文案。
2. 入口与交接迁移：保留八阶段和文件名。入口说明覆盖边界，validation 明确阶段输入与返回；文案文件增加条件读取路由，拆清执行顺序和展示顺序。
3. 唯一归属迁移：树显示规则移入第5步，来源重叠首次核对移入第2步；原入口保留明确链接。模板增加读取提示，不改变示例内容或生成接口。
4. 本轮验收：逐条比对、链接检查、真实案例路径推演及现有回归。生产检查器不改。

历史问题、业务语义调整、检查器增强另批处理。时期解析、旧标题兼容、字数门槛、结果覆盖检查、A_范围、题组局部变化的解释不在本轮裁决。

## 优先级与覆盖边界

适用范围先于覆盖。不是“专项或数据库文件总是更高优先级”。

| 层次 | 决定什么 | 不得做什么 |
| --- | --- | --- |
| 用户当前明确指令与已确认裁决 | 本任务范围及明确授权的例外 | 不把旧稿、历史通过或一句来源推荐当作确认 |
| 已确认业务方案 | 当前主题变量、来源、时期、算法、缺失和结果关系 | 不覆盖公共执行要求，不由文案或模板重新决定 |
| 公共规则 | 通用执行、交付及验收要求 | 不掩盖数据库真实差异 |
| 专项规则 | 在明确触发条件内细化公共要求；只采用明确写出的例外 | 不因“更具体”而自行推定覆盖 |
| 数据库差异 | 身份、文件、时期、编码、接口及已验证范围 | 不重定义共同写作、流程或主题算法 |
| 模板、示例 | 输入语法与表达示范 | 不覆盖正式规则、不提供本主题事实 |
| 程序检查 | 执行实际编写的检查并给出证据 | 不裁决业务含义；通过不证明语义正确，失败不授权改口径 |

冲突处理：核对作用对象、触发条件和明确例外。已有明确裁决覆盖的事项按裁决执行并保留范围；确有矛盾而无明确依据时记录原文、影响和选项，只暂停依赖部分，继续其他工作。不按文件日期、模板写法或程序输出来选一版。

## 结果关系与树的分工

来源方案确认哪些是最终结果、组成、中间量、平行结果，以及合成/分类关系，使用既有 definition_plan 等记录。文案阶段复核是否已说清及是否与方案一致，不另立方案。Criteria 清楚后，关系树选择布局并编码这些既定关系。关系缺失返回来源方案；结构标记错误留在文案阶段修正。

## 三类实际案例与读取路径

路径均相对于 Skill 或配置的 formal_root/process_root。以下是同一份真实方案的执行路径推演，不是重新定义或重新下载。阅读量按指定章节的字符、行和文件数量计算，不等于模型耗时。统计在 path-comparison.json 中保留选取范围和计数。

### 共同执行骨架

新建完整主题每阶段读取对应阶段文件；不能因变量简单免除来源核实、规定的独立 R 复核或交付验证。已经读过且输入未变的内容不重复读取。

| 进入节点 | 必读文件及内容 | 条件读取及触发 |
| --- | --- | --- |
| 入口 | SKILL.md：范围、边界、阶段和数据库路由；validation.md：默认路径及当前返回分支 | 只同步从第8步进入；只读解释不进入生产 |
| 来源 | 01-source-plan、evidence-and-literature、所选数据库 profile/workflow 的来源/身份/时期部分；exploration-record、definition-search-record；02 的来源命名 | 环境变化读新设备准备；用本地字典读 local-source-evidence；实际用网站取证读01固定读取及 write-boundaries 浏览器节；其他数据库文件不读 |
| 下载 | 02-download：选择、别名、导出、下载后核验；所选库下载差异 | 有同概念同周期替代或优先合并来源时比较实际重叠；失败才进入对应找回路径 |
| 文案 | 03 的执行与读取、通用表达/格式、标题、摘要、Criteria、小book；reader-copy 对应基础格式；scoped-tasks 的 Copy-operations | 由下列案例的条件表选择依据、问卷、树、参考资料，不通读全部示例 |
| R | 04-public-r、public-r-dictionary.R、所选库实现差异；definition_plan 和文案 | 稳定实现预检后按 review-roles 复核；改变事实回方案和文案 |
| 生成 | 05-generate：接口、输出、当前产物涉及的展示要求 | 实际存在树或问卷时核对对应显示；只写文案不预读具体字号 |
| 验证/交接 | 06-results、07-review、validation 的当前状态/影响要求 | 仅规定的额外验收触发时读相应角色；不自行增加固定审稿 |
| 同步 | 08-website、write-boundaries 浏览器节 | 仅在授权和当前许可满足后；结果未知按既有恢复边界 |

execution-report 在启动生产记录时读取；scoped-tasks 仅当前入口及 Copy-operations；index 和本维护记录不列入普通生产路径。

### S：简单变量

真实依据：KNHANES/001_人口学的 A_sex，正式方案为官方性别标签、有效值保留，其他已核缺失为 NA；该主题共有15个结果。用该变量检验简单定义路径，不把它从已有主题另立或发布。

| 类型 | 文件与内容 | 触发条件 |
| --- | --- | --- |
| 必读 | 共同执行骨架；03基础栏目；reader-copy 标题、摘要基础写法、Criteria基础模板、小book格式 | 完整任务或相应栏目变动 |
| 展示判断 | 03 问卷展示判断、依据条件表、关系树使用条件 | 只判断实际内容是否需要，不凭“人口学”一律省略 |
| 条件读取 | 问卷详细语法和实例 | 发现该结果需要原题消除歧义或依赖提问条件时；本例未触发 |
| 条件读取 | 依据详细写法和参考资料模板 | 有实际标准选择/方法资料时；性别直接保留不触发 |
| 条件读取 | 树的节点和语法、并列结果实例 | 审核整篇15变量人口学时触发；只说明性别且树无助理解时不触发 |

预计读到：实际取值、特殊缺失、独立可读的定义、结果计数和相关标签格式。不会为简单定义读取 ADL 前置题完整实例、量表比较或树的 CSS 数值。

### Q：跨期问卷和多题跳转

真实依据：KLoSA/004_吸烟，9个结果；首访累计经历与追访期间经历在同一结果中按期说明；C103/C104筛选、后续数量和时间题存在依赖。

| 类型 | 文件与内容 | 触发条件 |
| --- | --- | --- |
| 必读 | 共同执行骨架、03基础栏目、跨期结果合并、问卷完整规则；reader-copy单题组模板 | 实际存在跨期题义/回顾期及提问路径变化 |
| 条件读取 | 题组内部小标题模板、分期展示实例 | 同组需按流程分块或不同设计分期；本例触发分期，是否内部分块据实际结构 |
| 条件读取 | 关系树规则和主题为根模板 | 本例的经历、当前状态、分类和数量/时间关系需要展示 |
| 条件读取 | Copy-operations相应展示字段 | 翻译、首期标识、选项复用或正常顺序分支确实出现在证据中 |
| 条件读取 | 定义依据详细写法 | 真正采用标准或需解释方法选择时；不因存在派生分类就填标准比较表 |

预计读到：同一结果的时期差异、实际跳转与顺序作答的区别、原题与数据字段对应、完整题组和必要条件。不会因选择一个问卷模板套入 ADL 的补零业务。

### C：复杂综合指标

真实依据：CHARLS/052_内在能力，30个结果、14个来源组；连续五领域综合评分与受损分类两套关系、时期和完整性条件均来自已有方案。旧文案结构不作为当前语法标准。

| 类型 | 文件与内容 | 触发条件 |
| --- | --- | --- |
| 必读 | 共同执行骨架、03全部适用内容；依据与Criteria；关系树、问卷规则；所选库特殊编码 | 多层组成、不同算法和方法依据实际存在 |
| 条件读取 | reader-copy综合结果为根实例、综合Criteria实例、标准比较模板 | 本例触发；模板只能表达已确认两套关系，不重新决定算法 |
| 条件读取 | 分期问卷和内部小标题实例 | 依据题组的真实联系和变化触发，不照树强制拆问卷 |
| 条件读取 | 来源重叠核对 | 仅同概念同周期来源被视为替代或优先合并时；复杂不等于必然重叠 |
| 条件读取 | 历史结构诊断/更新入口 | 要求改旧稿时，先识别旧标题；本轮不改旧稿，也不把旧格式失败扩成重做来源 |

预计读到：具体成分、计分方向、标准化、完整性、输出/中间量区别、跨期来源差异。不会把关系树编排当成重新选择临床阈值的入口。

## 规则与验收对应

迁移表中每一原文单元都有验收类别；下表定义类别的能力边界。无需为每条规则新增一项固定审稿或PASS字段。

| 类别 | 对象 | 现有有效方式 | 不能据此证明/当前缺口 |
| --- | --- | --- | --- |
| 自动检查 | 来源身份、字段、变量清单、结构、文件绑定 | source_record / reader_copy / output / readability 检查及对应测试 | 记录一致不证明官方事实正确；摘要计数与树完整覆盖仍有缺口 |
| 来源复核 | 题干、选项、周期、对象、跳题、官方方法 | 官方材料和逐期来源记录，独立探索及必要的定向补证 | 无法由关键词或“有引用”判断材料是否支持当前条件 |
| 语义审核 | 结果关系、合并/拆分、缺失选择、依据、小book用途、易读性 | 执行者按方案和真实材料核对；已有触发条件下的独立角色 | 无通用可靠自动判断；不把短句、字数或栏目齐全视为通过 |
| 生成渲染 | 标签、主题色、树线、字号、布局、全文保留 | 现有渲染测试、生成结构核对、需要时实际显示检查 | DOM或文本通过不等于所有浏览器视觉通过；本轮不操作网站 |
| 架构迁移核对 | 原文覆盖、条件不丢、路由可到达、程序未改 | 原文逐条映射、差异核对、文件/锚点检查、真实案例路径推演 | 不等于新Agent实跑成功率或时间改善 |

验收盲区保留：来源证据本身是否充分、同义结果是否正确合并、小book是否真正有用，仍需来源/语义复核。时期解析、旧标题诊断和隐藏长度门槛已有风险，不借本轮路由迁移修改程序。

## 迁移追踪办法

migration.jsonl 按原文的独立段落、列表项、表格行和完整代码例逐条登记；一个原条文内存在多个条件时保留整段，不截断例外。标题也登记，用于追踪归属。每条包含原文/原位置、章节上下文、新位置、新原文、触发条件、验证类别、迁移状态及检查结果。

保留原位的条文也登记去向。原文完整保留可用文本定位验证；只有读取、归属或交接文字改变的条文须另外核对含义。原有复合条文不因追踪表而成为新的业务要求。本轮不合并存在不同条件的条文，也不删除无法判断的要求。

状态：retained（原位保留，行号可能变化）、moved（原文移动）、routing_updated（读取/交接说明调整）、pending_semantics（原文保留、语义问题另批）。新加路由单独登记 additions，不冒充旧要求。

## 新旧路径评价与验收门槛

1. 读取负担：比较相同任务入口、相同输入状态；完整写作的旧路径按原文要求读03与reader-copy全文，新路径按条件读取同两文件的相应部分。局部更新的旧路径本来已按章节读取，不能把全文基线套给局部任务夸大收益。
2. 规则遗漏：逐条原文去向完整；条件不适用的规则有明确排除理由，不以文件未读代替判断。
3. 执行一致性：同一方案下，输出清单、计算条件、缺失规则、调查期及结果关系不变。
4. 范围扩张：用只改A_sex措辞、只修问卷、只上传等局部情境，确认仍从原局部入口进入；路径表不新增研究、下载、复核者或网站授权。
5. 回退：来源事实缺口回01；下载实际值偏差回对应来源决定；模板/程序冲突只暂停依赖部分；树标记错留03；显示错留05；发布绑定过期回07。
6. 证明边界：阅读行/字符减少和路径可到达是架构证据；首次执行可靠性须后续经授权的独立前向测试证明。本轮不假称已完成。

完成批次2、3后，保存路径统计、逐条核对和回归结果。若已有回归失败，区分本轮引入与基线已存在；只修本轮文档迁移相关问题，不顺手修生产行为。
