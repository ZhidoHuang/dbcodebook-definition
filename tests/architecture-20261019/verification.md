# 本轮架构迁移验收

## 实际改动

本轮只修改10份既有规则/模板文件，另保存本目录维护证据。没有增加生产任务必读文件，没有修改生产脚本、数据库事实、定义方案、真实案例文案或网站。

基线包含已有未提交修改。这里只说明本轮差异，不能把 git diff 相对 HEAD 中其他改动算作本轮成果。

1. SKILL.md：新增适用范围、优先级和冲突处理边界；阶段入口链接到明确读取表。
2. validation.md：原八阶段表补充输入、条件读取和失败返回，保留原交付及验收。
3. 01-source-plan.md：结果关系在方案中确认，沿用既有记录，不新增关系审批表。
4. 03-copy.md：按条件读原文件章节；执行顺序和展示顺序分开；文案复核既定关系，Criteria清楚后再画树。
5. 02-download.md / 06-results.md：首次来源重叠比较归第2步，第6步沿用有效结论核对实现。
6. 05-generate.md：接收原关系树颜色、字号、行距及旧树显示兼容条文；03保留语义语法及引用。
7. index.md：同步唯一归属；维护记录不进入普通生产路径。
8. reader-copy.md：仅增加按任务定位模板的说明，所有示例和业务数值保持不变。
9. ELSA workflow：只将来源重叠核对的引用直接指向第2步，避免经过第6步多跳转一次；适用条件不变。
