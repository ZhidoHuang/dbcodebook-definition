# 文案模板与实例

- 配合[文案写作要求](../references/rules/stages/03-copy.md)使用。
- 本文与要求的组成顺序一致，只展示模板和写法，不另设规则。
- 花括号内是填写提示，成稿时替换为实际内容；可选部分不用时删除。

实例节选自已有主题，并按现行格式整理；只借鉴表达，不把例中的变量、时期、阈值或缺失处理直接套入新主题。问卷是否展示按第3步判断；选中展示的题组须保留理解定义所需的完整题目和条件。

## 2. 标题

**模板**：

```markdown
# {数据库} — {中文主题}（{英文主题}）
```

**标题格式**：

```markdown
# ELSA — 生活质量（CASP-19）
```

## 3. 摘要：最终得到什么

**模板**（一个自然段，交代每个最终变量和总数；每项可以简短）：

```markdown
## 摘要导读

本主题定义“**{主要结果}**”，以及“**{其他结果}**”，共 **{数量}** 个变量。
```

**总分与分项的摘要写法**：

> 本主题定义“**CASP-19生活质量总分**”，以及“**生活掌控感**”“**自主性**”“**愉悦感**”和“**自我实现感**”四个维度得分，共 **5** 个变量。

**多个结果不构成总分的摘要写法**：

> 本主题定义“**是否工作**”“**劳动状态**”“**过去一个月是否找工作**”和“**是否办理退休手续**”，共 **4** 个变量。

**多项并列结果的摘要写法**：

> 本主题定义“**性别**”“**出生年**”“**年龄**”“**婚姻状态**”“**教育程度**”“**家庭人数**”和“**是否独居**”，共 **7** 个变量。

**关系树模板**：

```text
{组成结果}
└─ {合成关系与必要条件} → {综合结果}
                         ├─ {分类条件} → {类别一}
                         └─ {分类条件} → {类别二}
```

**关系树格式**：

```text
8 个症状化条目
├─ 相加（仅限 8 项均有效）→ CES-D-8 抑郁症状总分（0–8 分）
│                         ├─ 4–8 分 → 有升高抑郁症状
│                         └─ 0–3 分 → 无升高抑郁症状
└─ 统计有效项数 → CES-D-8 有效回答数（0–8 项）
```

**右侧汇合的写法**（保留三行中的半角空格；改动左侧文字后，汇合位置也要相应调整）：

```text
“即时词语回忆”（0–10） ─┐
                            ├→ 两项均有效时相加 → “词语回忆总分”（0–20）
“延迟词语回忆”（0–10） ─┘
```

**复杂综合定义的构成树模板**（按实际构成填写，不要求固定层数）：

```text
{综合结果} [{共同适用时期}]（{合成方法、得分方向和必要条件}）
├─ {成分一}
│  ├─ {分项一}（{有助于定位时列原题号}）
│  └─ {分项二}
└─ {成分二}
   └─ {分项三}
```

## 定义依据

根据[定义依据的写作要求](../references/rules/stages/03-copy.md#定义依据先说明标准再说明本次采用什么)选择下面一种模板；简单事实或计算没有标准选择问题时省略。

**有公认且适用的统一标准**：

```markdown
## 定义依据

本主题采用{标准名称、版本及来源链接}，适用于{人群和条件}。该标准由{组成}构成，按{计分或判定方法}得到{结果}。

本次在{数据库和时期}使用{对应测量}实现。{实际存在的替代或项目另定处理及理由；无则删除。}
```

**多个方案存在影响本次选择的实质差异**（列出已核实的可比方案；只有一套可用依据时直接说明采用理由，不凑比较）：

```markdown
## 定义依据

{一小段交代概念及来源；无需概念介绍时省略。}

### 文献的主要做法

| 方案与来源 | 怎样计分 | 关键差异 |
| --- | --- | --- |
| {方案名称及链接} | {主要方法} | {影响本次选择的差异} |

### 本次采用的定义

本次采用{明确的方案}，主要参考{来源}的{具体规则}。{紧接着说明采用理由及实际收益和代价。}

{本项目实际调整了什么，以及该项调整的理由和代价；没有调整则删除。}

适用于{人群和时期}；{必要限制及其影响}。各结果的完整计算规则见后面的 Criteria。
```

## 4. 原始问卷：调查实际问了什么

- 直接采用官方年龄或教育分类、用家庭人数判断独居等，不需要借助原题理解时，省略本节；需要“定义依据”时保留该节，其后接 Criteria，否则摘要后直接接 Criteria。
- 像ADL依据前置题跳题补值，需要展示有关上游题和目标题时，再采用以下模板；不照搬整个模块。

- 题目标题优先使用原问卷标注的变量名。
- 例如 KNHANES 2013–2015 年官方使用指南第 92 页标注了 `marri_1`，标题写 `##### marri_1`。
- 原问卷只有数字题号时，才写题号并附已核实的对应数据变量名。
- 下列题目标题占位符均按此填写。

**单一题组模板**（选项、进入条件和跳转只在实际存在时填写）：

```markdown
## 原始问卷

### {题组实际名称}

#### {适用时期}

##### 问卷设计

{第一组说明问谁、问什么、怎样提问、用于哪些结果。后续有变化才另开时期，标题改为“问卷设计变化”，说明改变了什么，并完整展示该时期的问题块。}

##### {原问卷变量名或题号}

{完整中文题干}

适用对象：{进入本题的真实条件；无则删除本行}

- {原始编码} {选项标签}
- {原始编码} {选项标签} → 跳至 {目标题号}

跳题说明：{不能归入选项的真实流程；无则删除本行}
```

**多个独立题组模板**（各自设置时期标签；题组不必逐层对应综合结果的构成树，题干和选项的写法同上）：

```markdown
## 原始问卷

### {题组一的实际名称}

#### {题组一设计相同的适用时期}

##### 问卷设计

{本题组的对象、程序及与结果的对应。}

##### {原问卷变量名或题号}

{本时期组的完整题干、选项、单位及必要前置条件和跳转。}

### {题组二的实际名称}

#### {题组二变化前的适用时期}

##### 问卷设计

{本题组的对象和程序。}

##### {原问卷变量名或题号}

{变化前的完整问题块。}

#### {题组二变化后的适用时期}

##### 问卷设计变化

{本题组具体改变了什么，以及本时期的对象和程序。}

##### {原问卷变量名或题号}

{变化后的完整问题块；不写“其余同前”代替本标签内必要的题干、选项或条件。}
```

例如某综合指标包含握力和视力，经核实握力各期一致而视力有变化，就将握力合为一个时期标签，只拆开视力的时期。具体年份由本次证据决定，不从这个示例推定。

**题组内部需要小标题时**（替换该时期的题目部分；“问卷设计”仍用五级标题，不增加分块专属设计栏目）：

```markdown
### {题组名称}

#### {适用时期}

##### 问卷设计

{本时期的设计说明。}

##### 上游问题

###### {前置题的原问卷变量名或题号}

{完整题干、选项及必要跳转。}

##### 原始问题

###### {目标题的原问卷变量名或题号}

{完整题干、选项及必要进入条件。}
```

**问题块内的分支流程模板**（仅在多条分支需要图示时使用）：

```text
{判定题号与题义}
├─ 回答“{真实选项}” → {去向题号与测试名称}
└─ 回答“{真实选项}” → {另一去向或结束}
```

**多期相同问卷的展示格式**（节选，仅展示第一题）：

```markdown
## 原始问卷

### 抑郁症状

#### Wave 1–11

##### 问卷设计

Wave 1–11 的常规 Core 本人主访谈采用以下八道题，请受访者回想过去一周的感受，逐项判断这些情况在过去一周的大部分时间是否属实。八题依次作答，题组内部没有跳题；代理访谈不回答本题组。这些回答用于八个症状条目、有效条目数、CES-D-8 总分和升高抑郁症状指示。

本次网站导出的原始数据已将这些回答解码为 Yes/No；以下按共同选项展示，原问卷编号与导出值分开说明。

##### PSCEDA

在过去一周的大部分时间里，您感到抑郁吗？

原问卷选项编码（Wave 1–5）：1=Yes；2=No。
原问卷选项编码（Wave 6–11）：01=Yes；02=No。

- Yes
- No
```

## 5. Criteria：每个变量怎样得到

**模板**（一个变量一组；此处不预设赋值、补零或缺失处理）：

```markdown
## Criteria

### analysis_variable

#### 定义

{变量的含义。}

#### 定义逻辑

{说明原始信息怎样成为本变量：直接保留什么，重新分成哪些类别，或怎样换算、合成；只写实际采用的方法。涉及不同对象、时期或来源时，就近说明。仅统一代码或标签时，不在这里重复分类中的整套对应。}
{确有补值、缺项计算等特殊处理时，在这里接着写具体条件和结果；没有则删除本行。一句能说清就一句，多步才用①②③，不把这两行固定写成两个步骤。}

#### 分类

{分类变量逐项列编码与含义；数值变量填写类型和单位。}

#### 注意点

{本变量必要的使用说明；没有则删除本栏目。}
```

**直接保留原分类的定义逻辑片段**：

> 保留原回答的四档困难程度：“没有困难”“有困难但仍可以完成”“有困难，需要帮助”和“无法完成”（2011、2013、2015、2018 年使用 `db012`，2020 年使用 `db005`）。

**计算公式与计算条件的写法**：

```markdown
### ADL_count

#### 定义

六项基础 ADL 中存在困难的项目数。

#### 定义逻辑

① `ADL_count = ADL_dressing + ADL_bathing + ADL_eating + ADL_transfer + ADL_toileting + ADL_continence`。
② 必须六项都能判断才计算；任一项仍缺失时，本变量保留缺失。

#### 分类

- [0–6] 整数，单位为项
```

**前置跳题补零的写法**（写在本变量的定义逻辑内）：

```markdown
## Criteria

### ADL_eating

#### 定义

吃饭是否有困难。

#### 定义逻辑

① “没有困难”记为[0]；“有困难但仍可以完成”“有困难，需要帮助”或“无法完成”记为[1]（2011、2013、2015、2018 年使用 `db012`，2020 年使用 `db005`）。
② 2011、2013、2015、2018 年，本题为空白，且 `DB001`、`DB004`、`DB005`、`DB006`、`DB007`、`DB008`、`DB009` 均回答“没有困难”，`DB002`、`DB003` 各自为空白或“没有困难”时，本项补为[0]；两道步行题只要有困难回答，就不补零。已有有效回答按原答取值。
③ 2020 年只按本题回答赋值；拒答、不知道、无法识别的编码及其它不满足补值条件的空白保留缺失。

#### 分类

- [0] 没有困难
- [1] 有困难
```

## 6. 小book：跨变量或整个主题的使用限制

**模板**（有必要的数据结构、调查设计说明或具体发现时替换省略句；下列实例不是每篇都要凑齐的提示类型）：

```markdown
## 小book提示

本主题没有需要单独提示的主题级边界
```

每条都编号，只有一条也写 `1. `；多条之间空一行，例如：

```markdown
1. {一句话说明理解结果所需的数据结构、调查设计或具体发现。}{必要解释。}

2. {另一项确实值得补充的发现，没有则删除本条。}{必要解释。}
```

首句不加粗，生成器自动使用数据库主题色；后面的解释保持正文色。编号独立在左，换行与正文起点对齐，不靠空格排版。

**CHNS 人—年长格式**：

```markdown
1. 结果采用人—年长格式。每行表示一名受访者在某一调查年的记录，同一个人可以在多个年份出现。
```

**KNHANES 系列横断面调查**：

```markdown
1. KNHANES 是系列横断面调查，各年分别抽取样本，并非追踪同一批人。结果按受访者和调查年排列，每行是一名受访者在该年的记录。
```

**跨期使用提醒的写法**：

```markdown
## 小book提示

1. `db011` 在 2011–2018 年表示洗澡困难，2020 年表示控制大小便困难。本主题按各期题义对应活动，没有把同名原始变量直接当作同一项活动。
```

**项目数量变化的提示写法**：

```markdown
## 小book提示

1. IADL 项目数的计数上限从 7 变为 9。Wave 1—3 的清单有 7 项，Wave 4 起增加“识别身体危险”和“交流”。比较各期结果时，需要考虑项目数量的变化。
```

**抽样范围变化的提示写法**：

```markdown
## 小book提示

1. 早期身体活动题的大量空白来自抽样安排，不代表没有活动。2011–2015 年只询问随机抽中的一半家庭，2018 年和 2020 年改为面向全体受访者。
```

## 7. 参考资料说明

**模板**（没有实际使用的方法资料时，省略整节）：

```markdown
## 参考资料说明

> 1. {材料名称、版本或年份及页码}说明{相关方法或限制}。本主题据此{具体采用之处}；{必要时说明本项目另作的决定}。
```

**官方技术资料的引用格式**：

```markdown
## 参考资料说明

> 1. Harmonised ELSA E technical codebook，PDF 第 168–177 页说明 CES-D-8 八个条目的计分方向、0–8 分总分以及代理访谈的结构性缺失。该材料支持条目方向与量表组成；其部分缺失时保留已观测条目之和的做法不作为本主题的缺失处理，本主题只计算八项完整者的总分。
```

**研究文献与指南的引用格式**：

```markdown
## 参考资料说明

> 1. [Hughes 等：A Short Scale for Measuring Loneliness in Large Surveys（2004）](https://pmc.ncbi.nlm.nih.gov/articles/PMC2394670/)，Table 1 与 Procedures 说明三题各计 1–3 分后求和，得分越高孤独感越强，研究中排除了任一题缺失的受访者。本主题据此采用完整三题求和；在数据中保留这些受访者并将总分记为缺失，是本定义的处理选择，不是 ELSA 统一缺失规定。
> 2. [ONS：Measuring loneliness: guidance for use of the national indicators on surveys](https://www.ons.gov.uk/peoplepopulationandcommunity/wellbeing/methodologies/measuringlonelinessguidanceforuseofthenationalindicatorsonsurveys)，第 8 节说明三题总分为 3–9 分、直接孤独题单独分析，并指出没有公认的孤独划分切点。本主题保留总分与直接回答，不另设二分类；直接题的三个类别仍取自 ELSA 原问卷，不采用 ONS 的不同选项设置。
```
