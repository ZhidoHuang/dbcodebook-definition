### 关系树模板

先按[关系树规则](../references/rules/copy/tree.md#关系树)选择结构。以下花括号是占位内容，须替换为已确定方案；没有对应结果或条件时删除相应分支。正式树不得保留占位提示。

同一主题默认一棵树，并填写标签名。主题内的内容分组作为分支；只有独立、平行的主题定义才分成多棵树。下方模板分别演示可选结构，不表示同一篇笔记要逐个使用。

示例中的 result 表示最终输出。实际主题若不单独输出该节点，应改用 component，并说明其为中间计算量。来源、时期、取值及单位均用 meta。

**一、主题为根**

```text {主题简称}
{主题名称} [[meta:[{适用时期}]]]
[[relation:{整棵树的必要条件；没有则删除本行}]]
├─ 组成：{数量} 个条目
│  ├─ [[result:{分项一名称}]] [[meta:（{最终取值或单位}）]]
│  └─ [[result:{分项二名称}]] [[meta:（{最终取值或单位}）]]
├─ [[result:{总分名称}]] [[meta:（{范围}）]]：[[relation:{合成方法和必要条件}]]
│  └─ [[result:{分类变量名称}]] [[meta:（{最终取值}）]]
│     ├─ [[relation:{分类条件} → {类别}]]
│     └─ [[relation:{分类条件} → {类别}]]
└─ [[result:{辅助结果名称}]] [[meta:（{范围或单位}）]]：[[relation:{统计方法}]]
```

meta 的三种写法如下。它们是不同节点的独立示例，不要求在同一棵树重复展示。

- 最终症状变量：`[[result:感到抑郁]] [[meta:（0/1）]]`。
- 中间计分项：`[[component:感到抑郁]] [[meta:（0–3 分）]]`。
- 原始回答：`[[component:原题回答]] [[meta:（是/否）]]`，仅在原始回答确为是／否时使用。

**同一答卷形成两个总分**（虚构的六题／四题结构示例，不是实际量表；正式使用时替换为已定方案的具体条目名称、范围和算法）：

```text 两种总分
两种总分 [[meta:[示例时期]]]
[[relation:各总分所需条目全部有效才计算；计分条目不单独输出。]]
├─ 组成：同一答卷的六个条目
│  ├─ [[component:感到心烦]] [[meta:（0–4 分；第1题）]]
│  ├─ [[component:对处理问题有信心]] [[meta:（0–4 分；第2题）]]；[[relation:反向计分]]
│  ├─ [[component:感到紧张]] [[meta:（0–4 分；第3题）]]
│  ├─ [[component:难以应付事情]] [[meta:（0–4 分；第4题）]]
│  ├─ [[component:能够掌控局面]] [[meta:（0–4 分；第5题）]]；[[relation:反向计分]]
│  └─ [[component:因无法控制的事生气]] [[meta:（0–4 分；第6题）]]
├─ [[result:六项总分]] [[meta:（0–24 分）]]：[[relation:六项计分后相加]]
└─ [[result:四项总分]] [[meta:（0–16 分）]]：[[relation:仅取第1、2、3、4项计分后相加]]
```

此例只有两个输出变量。树中展开条目是为了说明组成，不改变交付范围；若方案要求条目也作为结果输出，再将相应节点标为 result。反向公式写在 Criteria；缺失说明按[定义逻辑](../references/rules/copy/core.md#5-criteria每个变量怎样得到)规定的范围填写。

**并列结果按内容分组**（人口学示例，与上方 7 个变量对应；组名不计为输出变量，分组不表示相加或合成）：

```text 人口学
人口学
├─ 基本人口特征
│  ├─ [[result:性别]]
│  ├─ [[result:出生年]]
│  └─ [[result:年龄]] [[meta:（岁）]]
├─ 家庭与婚姻
│  ├─ [[result:婚姻状态]]
│  ├─ [[result:家庭人数]] [[meta:（人）]]
│  └─ [[result:是否独居]]
└─ 教育
   └─ [[result:教育程度]]
```

实际取值、编码和时期按已定方案补入 meta，不从本例推定。

**二、综合结果为根**

```text {结果简称}
[[result:{综合结果名称}]] [[meta:[{适用时期}]]]
[[relation:{整棵树的必要条件及得分方向；没有则删除本行}]]
[[relation:{各组成部分之间的实际计算关系}]]
├─ [[component:{组成部分一}]] [[meta:（{分值范围或单位}）]]：[[relation:{本层计算关系}]]
│  ├─ [[component:{分项一}]] [[meta:（{取值或单位}；{必要来源}）]]
│  └─ [[component:{分项二}]] [[meta:（{取值或单位}；{必要来源}）]]
└─ [[component:{组成部分二}]] [[meta:（{取值或单位}）]]
```

本模板中的 component 不单独输出。实际输出这些分项时，改为 result。

│  ├─ [[component:两次步行平均时间]] [[meta:（{单位}；QG002、QG003）]]；[[relation:反向计分]]

## 定义依据

根据[定义依据的写作要求](../references/rules/stages/03-copy.md#定义依据先说明标准再说明本次采用什么)选择下面一种模板；简单事实或计算没有标准选择问题时省略。

优先选择能讲清信息的图表；下方表格可用于一套或多套依据。关系图用于组成或分支，纯文本用于不适合图表的内容及必要补充。只填有证据且与本次选择有关的行，不照搬示例问题。

**一套依据或多项采用决定**：

```markdown
## 定义依据

| 注意事项 | 详情/依据 | 本次处理 |
| --- | --- | --- |
| {实际问题} | {资料名称及链接、具体建议及理由} | {采用什么、必要条件；另作选择时说明理由} |
```

**HRS CES-D**（本例的选择不作为其他主题的默认方案）：

| 注意事项 | 详情/依据 | 本次处理 |
| --- | --- | --- |
| 量表版本 | 1992 年为 11 项频率版，后期为 8 项二元版 | 分别计分，不合并 |
| 1992 年代理回答 | [DR-005](https://hrs.isr.umich.edu/sites/default/files/biblio/dr-005_0.pdf)建议排除：无法确定描述的是谁的感受 | 仅纳入本人回答 |
| 1992 年插补回答 | DR-005 分析时将插补回答恢复为缺失 | 沿用，不参与总分计算 |
| 缺项计分 | - | 仅对完整回答计分；1993 年从原题重算 |
| 分类界限 | DR-005 讨论 CES-D-8 ≥4 分 | 采用该界限；不作为临床诊断 |

**不适合图表时的纯文本写法**（以下以一套适用标准为例）：

```markdown
## 定义依据

本主题采用{标准名称、版本及来源链接}，适用于{人群和条件}。该标准由{组成}构成，按{计分或判定方法}得到{结果}。

本次在{数据库和时期}使用{对应测量}实现。{实际存在的替代或项目另定处理及理由；无则删除。}

{资料名称}建议{处理}，因为{资料说明的原因}。本次采用该建议，{对应做法及适用范围}。{仅部分时期或对象需要该处理时，说明关键区别；无则删除。}

{本项目另作的选择及理由；无则删除。}
```

## 4. 问卷：调查实际问了什么

- ADL 的上游筛查与六项 ADL 有跳题联系，放在同一“日常生活活动”题组内，用“ADL上游问题”和“ADL原始问题”分块，见下方分期问卷示例。展示题组后，保留本主题定义所用的相关原题及必要路径；不因直接取值而删题，也不抄入无关模块。
- 直接采用官方年龄或教育分类、用家庭人数判断独居等，不需要借助原题理解时，省略本节；需要“定义依据”时保留该节，其后接 Criteria，否则摘要后直接接 Criteria。

- 题目前保留原问卷的标识：原来是题号就用题号，是变量名就用变量名。合并多个时期时，使用第一个时期的标识。
- 下列题目标题占位符均按此填写。

代码本的空白条件和记录状态保留在内部证据，不写入以下问题块；必要跳题按触发选项和实际去向展示。

基础写法已随操作迁入 [对应任务](../references/rules/copy/questionnaire.md#基础模板)；下方只保留条件实例。

“各个时期的变量名”属于小字号备注，放在题干后、选项前，不属于题干。与标题相同且无补充信息时删除本行。下面示范同一来源在不同位置使用哪个名称：

| 位置 | 示例 |
| --- | --- |
| 问卷题目标题 | GL005 |
| 题干后备注 | 各个时期的变量名：Wave 3 `sl_gl005_`；Wave 7 `gl005_`。 |
| Criteria 中需要补充来源名时 | Wave 3 使用 `sl_gl005_`，Wave 7 使用 `gl005_`。 |
| R 中读取的业务列 | `data$life_stress_1`、`data$life_stress_2` |

R 行中的 `life_stress_1`、`life_stress_2` 是为编程设置的下载别名。实际名称从来源映射核对，不照抄本例。

变量名备注的其他写法：

```markdown
各个时期的变量名：2004 年 `JD111`；2006 年 `KD111`；2008 年 `LD111`。
```

**多个独立题组模板**（各自设置时期标签；题组不必逐层对应综合结果的构成树，题干和选项的写法同上）：

```markdown
## 问卷

### {题组一的实际名称}

#### {题组一设计相同的适用时期}

{本题组的对象、程序及与结果的对应。}

{本时期组的完整题干、选项、单位及必要前置条件和跳转。}

### {题组二的实际名称}

#### {题组二变化前的适用时期}

##### 问卷设计

{本题组的对象和程序。}

##### {原问卷变量名题号}

{变化前的完整问题块。}

#### {题组二变化后的适用时期}

##### 问卷设计变化

{相较哪个时期，哪些人的哪些问题发生了什么变化。进入条件有变化时写出实际条件，再补充必要设计信息。}

##### {原问卷变量名题号}

{变化后的完整问题块；不写“其余同前”代替本标签内必要的题干、选项或条件。}
```

例如某综合指标包含握力和视力，经核实握力各期一致而视力有变化，就将握力合为一个时期标签，只拆开视力的时期。具体年份由本次证据决定，不从这个示例推定。

变化说明的句式示例（假设事实，仅演示表达）：

> 相较 Wave 1，Wave 2 的工作满意度题增加了暂时休假但仍保留工作的人；问题和四档选项不变。

这句话说明了具体增加谁。不能只写“受当期就业分支限制”；本例也不替代后面的完整问题块。

## 5. Criteria：每个变量怎样得到

基础写法已随操作迁入 [对应任务](../references/rules/copy/core.md#criteria任务)；下方只保留条件实例。

**直接保留原分类的定义逻辑片段**：

> 保留原回答的四档困难程度：“没有困难”、“有困难但仍可以完成”、“有困难，需要帮助”和“无法完成”。

**由测量值计算指标的片段**：

> 体重（kg）除以身高（m）的平方，得到 BMI；身高以 cm 记录时，先除以 100 换为 m。

**跨期来源的紧凑写法**（按已核实来源灵活列举或简写，不以字段数量决定使用表格）：

```markdown
#### 定义逻辑

保留各期“起床并离开房间”题的三档帮助程度（Wave 1–10，使用 `w01C205`—`w10C205`）。
```

**不规则来源与规则来源并存**：

```markdown
（1992–2000 年使用 `V305`、`V852`、`W307`、`D1834`、`E1858`、`F2391`、`G2689`；2002–2022 年使用 `HG001`、`JG001`—`SG001`。）
```

简写只用于正文展示，实际时期与完整字段对应仍按来源记录保存。上述时期和字段属于示例，不套用到其他题目。

变量名与英文取值的格式示例：`A_sex` 取值为 [Female] 时，表示女性。具体名称和取值按已定方案填写。

**同一变量保留跨期口径差异**（示例；实际时期和来源按方案填写）：

```markdown
### Sm_experience

#### 定义

是否有达到 100 支的吸烟经历。首次访谈问一生累计，后续访谈问上次访谈以来。

#### 定义逻辑

① 首次访谈使用生涯累计吸烟题；后续访谈使用上次访谈以来的吸烟题。
② 各期保留是否回答，统一编码为 0/1。

#### 分类

- [0] 否
- [1] 是

#### 注意点

回顾期随访谈类型变化。后续访谈回答否，不代表一生累计吸烟不足 100 支。
```

**计算公式与计算条件的写法**（六个组成变量已分别定义为 0/1 结果）：

```markdown
### ADL_count

#### 定义

六项基础 ADL 中存在困难的项目数。

#### 定义逻辑

① 将穿衣、洗澡、吃饭、起床、如厕和控制大小便六项困难结果相加，得到困难项目数：`ADL_count = ADL_dressing + ADL_bathing + ADL_eating + ADL_transfer + ADL_toileting + ADL_continence`。
② 必须六项都能判断才计算；任一项仍缺失时，本变量保留缺失。

#### 分类

- [0–6] 整数，单位为项
```

**使用已有定义结果继续判定的片段**：

> 根据已定义的 ADL 困难项目数（`ADL_count`），至少 1 项有困难时记为 [1]，0 项时记为 [0]。

## 6. 小book：跨变量或整个主题的使用限制

基础写法已随操作迁入 [对应任务](../references/rules/copy/core.md#小book任务)；下方只保留条件实例。

**数据结构与跨期差异的完整写法**（示意；时期和题项必须换成本主题已核实事实）：

```markdown
## 小book提示

1. 结果采用人—年长格式。每行是一名受访者在某一调查年的记录，同一个人可以在多个年份出现。这是一项追踪调查。

2. 早期和后期询问的活动数量不同。早期只问步行、爬楼和提重物，后期还询问其他活动。比较这些时期时，可对应查看共同询问的活动；早期未问的项目不能解释为没有困难。
```

这个示例交代记录结构和题目覆盖对比较的影响。研究记录转为小book时，只保留处理后的结果及使用影响，不展开处理步骤。例如，已核实某主题有两类异常，可这样取舍：

| 研究记录中的内容 | 正文处理 |
| --- | --- |
| 12条记录的结束年早于开始年，按已定方案保留；检查程序已通过，原文件未修改 | 小book写：“部分记录的结束年早于开始年。本次保留这两个原始年份，因此不能直接相减作为持续时间。”数量、检查和文件操作留在过程记录。 |
| 5条未满18岁记录有回答，本次不计分；定义逻辑已完整说明年龄限制 | 不另写小book重复这项条件。若它还影响多个结果共同使用，只补充那项具体影响。 |

上述人数只用于展示取舍，不是其他主题的事实。计算和赋值方法放定义逻辑；单个变量的使用限制放注意点；多个结果或整个主题的使用影响放小book。

**CHNS 人—年长格式**：

```markdown
1. 结果采用人—年长格式。每行表示一名受访者在某一调查年的记录，同一个人可以在多个年份出现。
```

**KNHANES 系列横断面调查**：

```markdown
1. KNHANES 是系列横断面调查。各年分别抽取样本，并非追踪同一批人。结果按受访者和调查年排列，每行是一名受访者在该年的记录。
```

**跨期使用提醒的写法**：

```markdown
## 小book提示

1. `db011` 的题义发生了变化。它在 2011–2018 年表示洗澡困难，在 2020 年表示控制大小便困难。本主题根据各期实际询问的活动定义结果，没有把这两个时期的 `db011` 合成同一项活动。
```

**项目数量变化的提示写法**：

```markdown
## 小book提示

1. IADL 项目数的计数上限从 7 变为 9。Wave 1—3 的清单有 7 项，Wave 4 起增加“识别身体危险”和“交流”。新增两项也计入困难项数，因此后期项数较高可能来自题目增加，不能直接解释为日常生活能力下降。
```

**抽样范围变化的提示写法**：

```markdown
## 小book提示

1. 早期身体活动题的大量空白来自抽样安排。2011–2015 年只询问随机抽中的一半家庭。2018 年和 2020 年改为面向全体受访者。因此，早期因未被抽中而没有回答的人，不能据此判为没有活动。
```

## 7. 参考资料说明

**官方技术资料的引用格式**：

```markdown
## 参考资料说明

Harmonised ELSA E technical codebook，PDF 第 168–177 页说明 CES-D-8 八个条目的计分方向、0–8 分总分以及代理访谈的结构性缺失。该材料支持条目方向与量表组成；其部分缺失时保留已观测条目之和的做法不作为本主题的缺失处理，本主题只计算八项完整者的总分。
```

**研究文献与指南的引用格式**：

```markdown
## 参考资料说明

[Hughes 等：A Short Scale for Measuring Loneliness in Large Surveys（2004）](https://pmc.ncbi.nlm.nih.gov/articles/PMC2394670/)，Table 1 与 Procedures 说明三题各计 1–3 分后求和，得分越高孤独感越强，研究中排除了任一题缺失的受访者。本主题据此采用完整三题求和；在数据中保留这些受访者并将总分记为缺失，是本定义的处理选择，不是 ELSA 统一缺失规定。
[ONS：Measuring loneliness: guidance for use of the national indicators on surveys](https://www.ons.gov.uk/peoplepopulationandcommunity/wellbeing/methodologies/measuringlonelinessguidanceforuseofthenationalindicatorsonsurveys)，第 8 节说明三题总分为 3–9 分、直接孤独题单独分析，并指出没有公认的孤独划分切点。本主题保留总分与直接回答，不另设二分类；直接题的三个类别仍取自 ELSA 原问卷，不采用 ONS 的不同选项设置。
```

生成器按上述材料顺序输出引用块编号；条目之间不留空行。文案中的链接和用途说明原样保留。
